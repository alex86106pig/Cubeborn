# game-icons.net 的圖示原檔

骰子模式的技能與效果圖示（`godot/assets/icons/<id>.png`）用這裡的剪影合成：`godot/tools/compose_icons.gd`（效果 YangHsu 2026-11-24、技能 2026-11-25）。

原檔來自 game-icons.net 官方 repo（https://github.com/game-icons/icons ，效果 2026-11-24、技能 2026-11-25 下載），沒有修改；合成時拿掉黑底、圖改成深色、加環（技能金色、效果照規則上色）。授權照 repo 的 `license.txt`：沒標 CC0 的作者都是 CC BY 3.0。
