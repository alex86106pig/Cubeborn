# 製作計畫

> 把 `docs/設計方向.md` 拆成一個個**做完就能自己驗收**的小里程碑。每一步都寫：做出什麼、使用者怎麼驗證、`check.gd` 補什麼檢查、開工前要問什麼。
> 階段的先後順序是 Claude 的建議，**使用者還沒拍板**；要調整就直接改本檔。里程碑完成就**刪掉該段細節**，只在總覽表留版號（細節在 CHANGELOG、`docs/系統說明.md` 與 git 歷史）。
> 「你怎麼驗證」以**實際玩**為主，數字類的目標要附實測結果（規則見 `CLAUDE.md` 2.4）。

## 原則
- **一個里程碑 = 一個版號**，做完就能玩、能看到差別；看不到差別的底層工作（例如屬性系統），要附一個「除錯用」的看得到的方式（面板、除錯鍵）。
- **先單機、後連線，但資料形狀一開始就照連線規格**（`PROJECT_GUIDELINES.md` 第 16 節）：B 階段全部做完才接 C，因為跳躍高度、攻擊判定、物品編號都會改到連線要同步的資料。
- **實體用繼承、內容用資料**：種類不同的東西（玩家、敵人、投射物、可互動物件）用繼承；數量多、差在數值或效果的東西（武器、道具、詞條、怪物種類）用資料表 + 可組合的效果，不為每個道具寫子類別。
- 牽涉核心玩法的細節，開工前照「開工前要問」先問使用者，不自己決定。

## D. 第 1 層：墓地
### D1 墓地地圖 — A 完成 v0.22.0（規格見 `docs/系統說明.md` §9）；B、C、D 待做
- **做出什麼**：固定的墓地地圖（不再是空場地），有牆、墓碑、高低差，地圖外圍封閉。怪物會繞牆、跳上高台，沒有安全區。
- **你怎麼驗證**：走完整張地圖，不會卡進牆裡或掉出地圖；跳得上該跳的地方。站上高台，骷髏戰士會蹲一下再跳上來、弓手照樣射得到；躲進王族墓圍牆裡，怪物會繞到北門進來。
- **已決定**：先做 A 環形墓園（96 × 96）；B 山坡墓道、C 廣場三翼、D 開闊墓原之後也做，每場隨機一張（草圖 `mockups/graveyard_map.html`，四張都做完再刪）；「5 分鐘走完」先不管；怪物跳上高台前蹲 0.25 秒（Claude 訂）。
- **B、C、D 開工時要處理**：B 的台地高差是不是都 ≤ 1.1（怪物跳得上去）；C 從出生點直衝挖墳點只要約 10 秒；隨機抽圖時房主要把地圖編號傳給客戶端。

### D7 第 1 層完整驗收
- **你怎麼驗證**：單人從進場玩到下一層入口，5 分鐘內走得完；兩人連線也走得完。回報難度感受，數字（存活時間、花費時間、死亡次數）記進 `docs/手感對照.md`。

## G. 道具第二批（2026-10-27 使用者決定：23 個一次全做）
- **做出什麼**：`ItemDefs.ITEMS` 45 個道具全部 `item_implemented`，祭壇 / 石棺 / Boss 獎勵抽得到全部道具（`LootDefs.drop_pool` 不再往下一級補）。
- **使用者的決定**：
  - 一次全做，做完才一起驗收；內部照 G1~G7 的順序、每步 `--check` 全過就 commit（不推送）。
  - 共用靈魂的道具看「動手的人」：錢袋 / 貪婪之手看擊殺者、撬鎖工具看開祭壇的人。
  - 守護亡靈、復活十字**都擋倒地**：在 `Player.die()` 進 `_go_down` / 真的死亡之前攔下（單機 = 歸零那一刻）；兩個都有時守護亡靈先用。已經倒地後倒數結束的死亡不攔。
  - 沒寫的數值 Claude 暫定（下表），寫進 `ItemDefs.PROCS`；快速武器會觸發過頻的效果加**內部冷卻**。磁石兩種撿取範圍（F 互動 1.6、金幣自動撿 1.2）都放大。
- **暫定數值**（Claude，試玩後調；傷害一律 `proc`：不爆擊、不觸發命中效果，打死照樣觸發擊殺效果）：

| 道具 | 暫定 |
|---|---|
| 蝙蝠牙 | 非 proc 命中回 1，內部冷卻 0.3 秒 |
| 血族王冠 | 非 proc 傷害的 3%（打隊友不算） |
| 荊棘鎖甲 | 反彈「實際扣的血 × 50%」給近戰攻擊者（投射物、Boss 地面招不算） |
| 爆裂箭袋 | 玩家的非 proc 投射物命中時，沿用 `explode`（半徑 2.5、該下 50%） |
| 王墓之心 | 半徑 3、受傷量 300%，內部冷卻 0.5 秒；傷害基準是扣血前的量 |
| 永恆之焰 | 命中點燃（沿用火把 `Enemy.apply_burn`）；燃燒中的怪每 1 秒把剩餘燃燒傳給 2 單位內 1 隻沒在燒的 |
| 袖中飛刀 | 左鍵普攻 20%，飛刀 60%、速度 18、射程 10；內部冷卻 0.3 秒 |
| 裂空之刃 | 只算左鍵普攻；±15° 兩道穿透斬波、射程 8、各 50%；內部冷卻 0.3 秒 |
| 雷霆鈴 | 每 5 秒打 8 單位內最多 3 隻，每隻 = 手上武器基礎傷害 × 150% × 攻擊力 |
| 停滯懷錶 | 翻滾開始時，半徑 5 內的怪移速與出招速度 ×0.3、2 秒（Boss 也吃，但只 ×0.6） |
| 骨製護盾 | 盾量 8% 最大生命、先扣盾；3 秒沒受傷一次回滿；血條上疊白色盾條 |
| 守護亡靈 | 留 1 血、無敵 2 秒，每層一次（`next_floor` 重置） |
| 復活十字 | 回 50% 血、無敵 2 秒，用完從背包移除（空出格子） |
| 鬼火燈籠 | 擊殺時放 1 顆追蹤鬼火：速度 8、存在 4 秒、打擊殺那一下的 80%；同時最多 6 顆 |
| 亡者大軍 | 骷髏僕從：沿用 MeleeEnemy、隊伍算玩家方、血 60、傷害 8、存在 20 秒、不打玩家、不給靈魂；每人最多 3 隻 |

- **步驟**（每步：改程式 → 加進 `IMPLEMENTED_*` 或把屬性 `in_use` 改 true → `loot_checks.gd` 補該道具的檢查 → `--check`）：
  1. **G1 純屬性 7 個**：`stat_defs` 把 7 個屬性 `in_use` 改 true，各接到使用處——`Combat._apply_damage`（命中回復、吸血、受到投射物傷害）、`World.on_enemy_died`（靈魂獲得，乘擊殺者的）、`Chest.try_open`（價格，乘開的人的）、`World.nearest_interactable` 與 `_collect_coins`（撿取範圍）、`Vision.view_range` 與扇形角度（視野，客戶端畫面也要讀到）。
  2. **G2 條件 3 個**：`CONDITIONS` 的 `after_roll`、`per_kill_stack`（換層歸零）、`from_elite`（魔法 / 稀有怪），在 `item_effects.gd` 照現有條件的寫法加類別。
  3. **G3 觸發 4 個**：新增觸發時機 `hurt_melee`、`hurt`、`projectile_hit`（`Combat._apply_damage` 依來源分辨），動作 `reflect`、`ignite`（含擴散）；`explode` 沿用。
  4. **G4 新動作 5 個**：`throw_knife`、`slash_wave`（沿用 `Projectile`，加新 visual）、`lightning_strike`（`interval` 觸發，在 `update_player` 計時）、`slow_time`（`Enemy` 新增減速倍率，移動與狀態機時間都乘）、`bone_shield`（`Player.shield`，快照多送一欄）。內部冷卻做成 `PROCS` 的 `icd` 欄位，共用一個計時表。
  5. **G5 生死 2 個**：`Player.die()` 開頭攔 `lethal` / `death`；復活十字用 `Loadout` 現有的移除流程；發事件給畫面與 RunLog。
  6. **G6 新實體 2 個**：鬼火（`Projectile` 加追蹤）、骷髏僕從（敵人加 `team`，`Combat.hostiles_of` 與怪物找目標都要看隊伍）；連線快照帶隊伍，`check.gd` 補快照大小仍在 4 KB 內。
  7. **G7 收尾**：`check.gd` 加「全部道具都已接上」；`--perf` 不能退步（帶滿僕從、鬼火、斬波的情境）；`docs/系統說明.md` 新增 §20；`docs/道具清單.md` 的「金幣」改「靈魂」；`docs/試玩清單.md` 加第 13 節；CHANGELOG「未發布」；`docs/進度.md`。
- **你怎麼驗證**：武器測試場或單機按 F4 逐個放入，每個道具看得到效果（測試場的木樁血很多，適合看傷害數字）；兩台連線時對方看得到僕從、鬼火、斬波，護盾條也有同步。
- **開工前要問**：無（上面都已決定）。爆炸、反彈打不打隊友沿用現在的規則（`Config.NET.friendly_fire` 開著就會打到，火藥包已經是這樣）。
