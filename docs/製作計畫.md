# 製作計畫

> 把 `docs/設計方向.md` 拆成一個個**做完就能自己驗收**的小里程碑。每一步都寫：做出什麼、使用者怎麼驗證、`check.gd` 補什麼檢查、開工前要問什麼。
> 階段的先後順序是 Claude 的建議，**使用者還沒拍板**；要調整就直接改本檔。里程碑完成就標 ✅ 並寫版號，詳細內容記在 CHANGELOG。
> 「你怎麼驗證」以**實際玩**為主，數字類的目標要附實測結果（規則見 `CLAUDE.md` 2.4）。

## 原則
- **一個里程碑 = 一個版號**，做完就能玩、能看到差別；看不到差別的底層工作（例如屬性系統），要附一個「除錯用」的看得到的方式（面板、除錯鍵）。
- **先單機、後連線，但資料形狀一開始就照連線規格**（`PROJECT_GUIDELINES.md` 15.7）：B 階段全部做完才接 C，因為跳躍高度、攻擊判定、物品編號都會改到連線要同步的資料。
- **實體用繼承、內容用資料**：種類不同的東西（玩家、敵人、投射物、可互動物件）用繼承；數量多、差在數值或效果的東西（武器、道具、詞條、怪物種類）用資料表 + 可組合的效果，不為每個道具寫子類別。
- 牽涉核心玩法的細節，開工前照「開工前要問」先問使用者，不自己決定。

## B. 打基礎（單機，連線之前做完）
### B1 角色屬性系統 ✅ v0.14.0（疊加、護甲、爆擊、冷卻縮減規則見 `PROJECT_GUIDELINES.md` 15.11；面板已截圖確認，F3 後移速 9.75 顯示金色）
- **做出什麼**：玩家與敵人都有一組屬性（最大血量、移速、攻擊力、攻速、暴擊率、暴擊傷害、防禦…），所有加成都經過同一套「基礎值 + 加值 + 百分比」的計算。現有數值改成從屬性讀，玩起來和現在一模一樣。
- **你怎麼驗證**：按 Tab 開屬性面板，看到各項數字；按除錯鍵給自己「移速 +50%」，面板從 6.5 變 9.75，實際跑起來明顯變快。
- **自動檢查**：加成疊加公式；套用前後的移速、傷害與網頁版數字一致。
- **已決定**：屬性清單對應道具清單（翻滾、背包、視野等的屬性已定名，系統做好再接上）；加成相加、冷卻縮減相乘、護甲 100 ÷ (100 + 護甲)、基礎爆擊 0% ×1.5。

### B2 翻滾閃避 ✅ v0.15.0（規格見 `PROJECT_GUIDELINES.md` 15.12）
- **做出什麼**：按鍵翻滾一段距離，期間有極短的無敵時間，有冷卻。
- **你怎麼驗證**：站在弓手箭的路線上翻滾，箭穿過去不扣血；F2 顯示判定時，無敵期間角色判定圈變色。
- **自動檢查**：翻滾距離、無敵秒數、冷卻秒數。
- **已決定**：左 Shift、0.35 秒翻 4 單位、前 0.2 秒無敵、回充 1.2 秒、往移動方向、可取消普攻前搖與後搖；速度與距離隨移速等比放大（含疾跑）。

### B3 高度與跳躍 ✅ v0.16.0（規格見 `PROJECT_GUIDELINES.md` 15.13）
- **做出什麼**：模擬層加入高度軸與重力；角色能跳，命中判定會比較高度。
- **你怎麼驗證**：測試場地放一個 1 格高的台階和一個 2 格高的牆，能跳上台階、跳不上牆；跳起來能躲過貼地的攻擊。
- **自動檢查**：跳躍最高高度、滯空秒數、落地；高度不同時攻擊不命中。
- **已決定**：空白鍵、最高 1.5、滯空 0.6 秒、一段跳；空中可攻擊、用技能、翻滾（照常下墜）；命中照實際高度；測試石台放場地角落。

### B4 通用攻擊判定（怪物取消碰撞傷害） ✅ v0.17.0（規格見 `PROJECT_GUIDELINES.md` 15.14）
- **做出什麼**：玩家與怪物共用一套「預備動作 → 判定 → 收招」的攻擊，判定有形狀（圓、扇形、矩形）、方向、高度、能不能被格擋。骷髏戰士改成揮砍招式，碰到玩家不再扣血。
- **你怎麼驗證**：貼著骷髏戰士站不會扣血，只有被牠揮到才扣；F2 顯示攻擊判定的形狀和出現時機。
- **自動檢查**：各形狀的命中範圍邊界；碰撞不扣血；預備 / 判定 / 收招秒數。
- **已決定**：骷髏戰士「中等」揮砍（舉刀 0.5 秒、100° / 1.5、傷害 12、冷卻 1.2 秒），舉刀時站定、後半鎖定方向；弓手與 Boss 不補近身招。

### B5 劍盾格擋與盾反 ✅ v0.18.0（規格見 `PROJECT_GUIDELINES.md` 15.15）
- **做出什麼**：劍盾右鍵改成格擋，前方範圍內的近戰與有方向的投射物擋得住；時機抓準觸發盾反，對前方範圍造成傷害。
- **你怎麼驗證**：面對弓手按右鍵，箭被擋下；背對就擋不住；Boss 砸地擋不住；完美格擋時出現盾反特效並打傷前方的怪。
- **自動檢查**：角度邊界、完美格擋時間窗、不可格擋的攻擊照樣扣血。
- **已決定**：按一下維持 3 秒、可以移動（×0.5）、拿掉盾擊衝鋒；左右各 37.5°、完美格擋 0.2 秒、盾反 25 傷害、冷卻 4 秒、翻滾可提前結束（後幾項由 Claude 訂）。

### B6 物品資料格式
- **做出什麼**：武器與道具都有唯一編號、稀有度、占格形狀、效果列表（效果作用在 B1 的屬性上）；`道具清單.md` 的 45 個道具轉成資料。還不做背包介面。
- **你怎麼驗證**：除錯鍵把指定道具「直接放進身上」，Tab 面板看到屬性變化（例如拿一個「暴擊率 +10%」的道具，面板的暴擊率跟著變）。
- **自動檢查**：編號不重複、每筆欄位完整、占格形狀合法、效果都對應到存在的屬性。
- **開工前要問**：資料放哪（程式資料表 / Godot Resource / 試算表匯出），Claude 會先列各做法的優缺點。

### B7 特效搬移
- **做出什麼**：從網頁版搬特效：揮砍弧光、盾擊衝擊環、魔彈拖尾、奧術預警與蓄力粒子、爆炸、命中粒子、爬出塵土、死亡碎骨、Boss 暈眩星星。網頁版直接呼叫的地方改成事件（`PROJECT_GUIDELINES.md` 15.6）。
- **你怎麼驗證**：和舊網頁版 `/legacy/` 並排玩，每種特效都出現且樣子接近；第一次出現時不卡頓。
- **自動檢查**：每個特效事件都有對應的畫面處理；特效數量上限。
- 這步可以和 B1~B6 穿插做，不影響連線資料。

## C. 多人連線（1~4 人合作）
### C1 兩個視窗連線
- **做出什麼**：開房 / 加入（區網 ENet），房主跑唯一的模擬，其他人送輸入、收快照。
- **你怎麼驗證**：同一台開兩個遊戲視窗，一個開房、一個加入，兩隻角色互相看得到對方移動，畫面不抖。
- **自動檢查**：headless 啟兩個程序連線，跑 10 秒後兩邊的玩家位置一致。

### C2 戰鬥同步
- **做出什麼**：怪物、攻擊、傷害、死亡、生成都由房主決定並同步；誤傷開啟。
- **你怎麼驗證**：兩人一起打完一局，兩邊看到的怪物血量、擊殺數、波次一樣；砍到隊友會扣隊友血。
- **自動檢查**：同一串輸入下，房主與客戶端的事件與狀態一致。

### C3 延遲下的手感
- **做出什麼**：自己的角色本機預測移動，收到快照後修正。
- **你怎麼驗證**：開啟模擬延遲 100 ms，自己的角色移動和單機一樣跟手；別人的角色移動平順。
- **自動檢查**：模擬延遲與掉包下，修正後位置誤差小於指定值。
- **開工前要問**：攻擊與技能要不要也本機預測；敵人依人數調整的方式；中途加入。（命中停頓 v0.18.3 已改成只做畫面定格，多人不用另外處理。）

### C4 倒下與救援
- **做出什麼**：倒下先假死、隊友靠近按互動救起；全員倒下就輸。（屍體裝背包與冤魂在 D3 背包做完後再接上。）
- **你怎麼驗證**：兩人連線，一人倒下，另一人走過去按互動救起；兩人都倒下出現失敗畫面。
- **開工前要問**：假死秒數、救援要按多久、救起後的血量、互動鍵。

## D. 第 1 層：墓地
### D1 墓地地圖
- **做出什麼**：固定的墓地地圖（不再是空場地），有牆、墓碑、高低差，地圖外圍封閉。
- **你怎麼驗證**：走完整張地圖，不會卡進牆裡或掉出地圖；跳得上該跳的地方。
- **開工前要問**：地圖大小與大致配置（Claude 先畫幾張俯視草圖給你挑，照 `CLAUDE.md` 2.5 做成對比頁）。

### D2 角色視野
- **做出什麼**：只看得到角色前方視野內的怪物、攻擊、寶箱；地形照常看得到。多人時各自只看自己的視野。
- **你怎麼驗證**：怪物走到身後就消失、轉身就出現；連線時隊友在自己視野外也看不到。
- **開工前要問**：視野角度與距離；視野外的攻擊要不要在快命中時才出現（`想法清單.md` 第 8 點的提醒）。

### D3 金錢、寶箱與背包
- **做出什麼**：殺怪掉錢（多人共用）、地圖上的小 / 大寶箱花錢開、格子背包（不規則形狀、可旋轉），放進背包的道具生效；屍體裝背包、冤魂復活接上。
- **你怎麼驗證**：殺怪看到錢增加，開寶箱拿到道具，拖進背包並旋轉擺放，Tab 面板屬性變化；背包滿了放不下。
- **自動檢查**：擺放與旋轉的碰撞判斷、金錢與寶箱價格、屍體占 2 × 3 格。
- **開工前要問**：寶箱價格、各稀有度機率、背包操作方式（滑鼠拖曳 / 按鍵）。

### D4 武器掉落與合成
- **做出什麼**：殺怪機率掉武器（多人只掉一把、先撿先得），最多拿 2 把可切換，同種同稀有度可合成高一級、詞條重新產生。
- **你怎麼驗證**：打一層撿到武器、切換、合成，看到稀有度與詞條變化。
- **開工前要問**：掉落率、詞條清單、切換武器的按鍵。

### D5 成群怪物與怪物稀有度（含效能）
- **做出什麼**：怪物一群一群分布在地圖上，有普通 / 魔法 / 稀有與詞條；小怪改用效能較好的畫法（單一網格加骨架，或同種一起畫）。
- **你怎麼驗證**：遇到一大群怪的割草感；稀有怪明顯比較難打。效能目標（數字開工前確認）：同時 200 隻怪時，alex_sanchong（RTX 3070）維持 144 FPS，內顯電腦 alex_work 至少 60 FPS。
- **自動檢查**：怪群生成數量與分布、稀有度機率與詞條套用；效能數字由壓力測試量測。
- **開工前要問**：每種稀有度的強化幅度、詞條清單。

### D6 挖墳事件與下一層
- **做出什麼**：定點累積進度（累積時不能動、可隨時取消、沒人時緩慢下降、被打不中斷）；事件開始後出現 Boss，怪物越來越多越難；所有人走進出口才進下一層。
- **你怎麼驗證**：開始挖墳看到進度條上升，放手會慢慢掉；Boss 出現、怪越來越多；不打 Boss 也能下去。
- **自動檢查**：進度上升 / 下降速度、難度隨時間上升的曲線、全員到齊才換層。
- **開工前要問**：累積總秒數、下降速度、難度上升速度、Boss 獎勵。

### D7 第 1 層完整驗收
- **你怎麼驗證**：單人從進場玩到下一層入口，5 分鐘內走得完；兩人連線也走得完。回報難度感受，數字（存活時間、花費時間、死亡次數）記進 `docs/手感對照.md`。
