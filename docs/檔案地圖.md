# 檔案地圖

> 要動程式時先查這裡定位模組，再用 Grep 找名稱、只讀需要的那段（`CLAUDE.md` 2.1）。新增、刪除、搬移檔案時必須同步維護此表（`CLAUDE.md` 1.5）。

| 檔案 | 職責 |
|---|---|
| `.github/workflows/pages.yml` | 推送 main 後自動：下載 Godot 與網頁模板 → 字型子集化 → 跑 `check.gd` → 匯出網頁版 → 加上 `/legacy/` → 發布 GitHub Pages |
| `.github/workflows/release.yml` | 推送 `v*` tag 後自動：跑 `check.gd` → 匯出 Windows 版 → 壓 zip（附連線說明）→ 建立 GitHub Release；一次推超過 3 個 tag 不會觸發，要手動跑 |
| `.gitattributes` | 換行一律 LF（Windows / Mac 共用）；`CHANGELOG.md`、`docs/進度.md` 用 union 合併（兩人同時在最上面加內容時 rebase 不衝突） |
| `README.md` | 給朋友看的首頁：試玩連結、操作、回報方式、版權；封面 `docs/images/screenshot.jpg` |
| `tools/release.mjs` | 檢查與推送（Node，Windows / Mac）：`--check` 匯入 + `check.gd`（有逾時）；`--summary "摘要"` 推送：rebase → 依 CHANGELOG「未發布」決定版號 → 改 CHANGELOG / `version.gd` → 檢查 → commit + tag → push，失敗就還原；`--dry-run` 試跑、`--bump=minor\|patch` 蓋過版號判斷 |
| `tools/subset_font.py` | CI 用：網頁版匯出前把字型只留程式裡出現過的字（需要 Python + fonttools） |
| `tools/serve_web.ps1` | 本機測試網頁匯出（`build/web`，`http://localhost:8060`）；檔案須維持純 ASCII |
| `legacy/` | **已凍結的網頁版（Three.js）**，網站 `/legacy/` 仍可玩。不修 bug、不加功能；內部結構看 `legacy/` 的原始碼，入口 `legacy/index.html`、自動檢查 `legacy/check.js`（`node check.js`，只有動到 `legacy/` 時才跑） |
| `build/web/` | 本機網頁匯出輸出（不進版控） |
| `CLAUDE.local.md` | 本機設定：電腦名稱、路徑、硬體（每台各一份，不進版控，見 3.3） |
| `docs/檔案地圖.md` | 本表：每個檔案的職責（`CLAUDE.md` 不再內含，v0.34.0 後搬出來省 token） |
| `docs/連線試玩.md` | 給朋友的連線說明：下載 Releases 的 Windows 版、虛擬區網、開房 / 加入、防火牆（也放進 Release 的 zip） |
| `docs/進度.md` | 跨對話交接檔；最上面的「通知」是給另一位作者的流程變更（看完就刪） |
| `docs/效能.md` | 效能量測數字（實際遊戲、壓力測試、渲染）與最佳化順序 |
| `docs/設計方向.md` | 設計目標與平衡品味（改核心玩法前必讀） |
