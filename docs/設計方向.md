# 設計方向

> 修改核心玩法（戰鬥手感、敵人行為、波次節奏、數值平衡、操作方式）前必讀。內容由使用者決定，AI 不可自行修改；「未定」的項目遇到時先問使用者。
> 細節還沒定案的點子在 `docs/想法清單.md`；道具草稿在 `docs/道具清單.md`。

## 總覽

| 項目 | 方向 |
|---|---|
| 一句話介紹 | 一群盜墓冒險者深入王族陵墓，1~4 人合作，一場約 2 小時的動作 Roguelike |
| 遊戲名稱 | 未定（候選見 `想法清單.md`；在定案前專案代號維持 Cubeborn） |
| 參考作品 | 雨中冒險 2（一場一場分開、道具疊加、去下一關的事件）、Minecraft Dungeons（每關的遊玩感、設計過的地圖）、Hammerwatch 2（地下城、角色視野、關卡與場景設計）、POE（怪物成群分布、普通 / 魔法 / 稀有怪與詞條、格子背包）、LORT（武器殺怪掉、錢開寶箱拿道具）、逃離鴨科夫（只看得到角色前方視野內的敵人）；場景風格另參考《葬送的芙莉蓮》零落的王墓 |
| 一局時間 | **正式版**：休閒玩家一路打到最終 Boss 約 2 小時。**測試階段**：做不到這麼長，先做 5 層、每層 5 分鐘內走得完 |
| 難度曲線 | 新手玩起來要很難。要靠「遊戲外成長 ＋ 操作技術 ＋ 熟悉道具與機制」才能有機會穩定通關 |
| 重玩動機 | 能穩定通關之後，靠不同 build 和職業（例如戰士通關後想試弓箭手）吸引玩家繼續玩 |
| 戰鬥重點 | 閃避走位、打擊感、像魂系一樣慎重（2026-10-29 許家慶決定：開局每一場戰鬥都要小心應對；割草感不是開局就有，是中後期組出好 build 的獎勵） |
| 成長方式 | 每局從頭開始，但有一點遊戲外的永久成長，讓玩家越玩越強、有成就感 |
| 人數 | 單人，或 2~4 人合作 |
| 不想要的東西 | 未定 |

## 一場遊戲的流程
- 第 1 層：地面的墓地（設計過的固定地圖，A~D 四張隨機一張，見「操作與視野」的地圖）。之後每層是地下陵墓。測試期共 5 層。
- 第 2 層「骸骨墓窟」（2026-11-02 YangHsu 決定）：地圖由 Claude 設計（3 × 3 墓室連成一圈，中央主墓室是出口與 Boss）；去下一層的事件是「撬開石棺封印」；挖墳點照圖鑑噴第 3 層的屍甲蟲與墓穴蜘蛛（這次一起做）。
- 地圖有設計過，怪物一群一群分散在地圖上；每層的資源與怪物數量有限。
- **去下一層的事件**：每層都有，第 1 層是「挖墳」，之後每層換成不同的形式（可以往惡搞方向），但本質相同（2026-10-28 許家慶試玩單人無法通關後改：挖太慢、要抽空打怪、近戰還要去追弓手）：
  - 有人在定點「累積進度 %」，累積時什麼都不能做，可以隨時開始、隨時取消；沒人累積時進度**不會下降**。
  - 被打**不會中斷**累積（超硬的坦克 build 可以扛著傷害直接累積完）。
  - 多人一起累積速度相加，所以總量隨人數放大（全員一起挖跟單人一樣久）。
  - **Boss 開局就在定點附近的 Boss 房巡邏**，不會走出 Boss 房；玩家進入 Boss 視野或打到它就開始追，追了之後不限範圍。玩家可以先打完 Boss 再開始，也可以直接開始、同時面對 Boss 與怪物。打死有獎勵（武器 + 道具）；不打死也能下去。
  - 碰到定點才開始事件：其他怪物開始不斷冒出、越來越多越難（稀有怪變多、數值變高）；同時定點每隔一段時間墳土隆起、裂開、冒出白骨手，接著噴出**下一層的怪物**（飛到空中再落下），每次噴出進度自動 +10%，噴的數量與強度也跟著難度。拖太久就會害死玩家。
  - 所有人的畫面上方都有明顯的進度條。
  - 進度滿了就**不再生怪**（已經出來的不會消失）：玩家清完怪可以喘口氣、整理背包、去開剩下的寶箱，準備好再到定點互動才前往下一層（測試版只有一層，互動就是通關）。
  - 多人：一人互動就發起投票並倒數，其他人 Enter 同意 / Esc 反對；全員同意或時間到就走，倒數中有人反對就取消（參考夢之形）。單人時怪物生成較少。
- **難度**：沒有全場時間難度。每層有固定的基礎難度（例如第 1 層 0、第 2 層 10），事件開始後難度從該層基礎值一路往上，可以超過下一層的基礎值；進度滿了就停。到了下一層一律從該層基礎值重新開始。
  - 小關成長（2026-11-03 許家慶：1-1~1-5 成長太小、1-2 起拿到道具技能就太簡單）：每過一個小關怪物生命 +20%、攻擊 +12%（跟難度相乘），後面的層照前面過了幾關算；數字 Claude 暫定。
  - 選角畫面選難度（2026-10-27 使用者決定）：簡單 / 普通 / 困難，只改事件開始後難度上升的速度 ×0.75 / ×1 / ×1.5，其他不動；多人由房主選。
  - 高風險高回報：開始事件前先打 Boss、清地圖上的怪群與寶箱，多賺錢、多拚武器掉落。
  - 數值（2026-10-23 決定，2026-10-25、2026-10-28 改）：挖墳每人 60 秒（總量 × 人數）、不會掉；定點每 10 秒噴一次（3 隻起、難度每漲 20 多 1 隻，強度用下一層的基礎難度起算），每次 +10%（單人一直挖約 40 秒挖完）；怪潮生怪間隔 5 → 1 秒、每 50 點難度多 1 隻；難度線性無上限（事件開始後每秒 +1）；每層基礎難度 +10；Boss 必掉武器 + 一個大寶箱機率的道具。

## 玩家拿到的東西
| | 武器 | 道具與技能 |
|---|---|---|
| 取得 | 殺怪機率掉落（多人時只掉一把，先撿先得） | 殺怪收集靈魂（多人共用），花靈魂開地圖上的祭壇 / 石棺（2026-10-26 使用者決定：盜墓主題，遊戲裡不用錢買寶箱）；開出**一個遺物**（技能、道具兩種外觀），每個玩家都能互動一次、各自 3 選 1，全員撿過才消失（2026-10-30 許家慶決定）；選項照機率全隨機，每人開局 3 顆骰子可以重骰（參考 Sephiria，增加骰子做進道具與局外成長） |
| 稀有度 | 白綠藍紫橘 | 白綠藍紫橘 |
| 稀有度差別 | 白色無詞條，每高一級多一條隨機詞條；**詞條都跟羈絆有關**（2026-10-30），魔力詞條例外（2026-11-02） | 越稀有越強，占的格子也越多 |
| 特殊規則 | **一個武器欄：單手武器＋副手，或一把雙手武器**（2026-10-30，取代原本 2 格裝備欄與 X 切換）；可以自由換武器，多的放背包；兩把**同一種、同稀有度**合成高一級（2026-10-23），2026-10-30 改成要到特定祭壇互動才能合 | **鑲在武器格子上才生效**（2026-10-30），背包只放多的東西 |
- **觸發袋（2026-11-04 YangHsu 決定，取代下面的「武器格子」與 11-03 的 Noita 法術線、背包星位；製作中，步驟在 `docs/製作計畫.md` H；討論過程與備案在 `docs/改版構想.md`；數字都是 Claude 暫定）**：
  - **第 8 步的新規則（YangHsu 2026-11-04 定案；還沒做進遊戲，步驟在 `docs/製作計畫.md` H 第 8 步，做完就併進下面各條）**：
    - **道具分成數值、技能、修飾三類**：原本的「效果」併進技能（小技能：便宜、佔格多；大技能：貴、佔格少）。這一步只併名稱與外觀（都畫圓框），發動與耗魔不變；重複的道具（技能冰霜新星與效果 `frost_nova`、閃電鏈與連鎖閃電）之後再處理。
    - **數值道具放主袋或袋子都生效**：多的袋子空間由玩家選擇放數值或加強技能。撿到時只自動放主袋、滿了進倉庫，放袋子要手動（Claude 建議，YangHsu 同意）。
    - **修飾有透明格，透明格蓋在技能上才有效**：只強化被蓋住的那個技能，取代「同一袋都有效」；同一個技能可以蓋很多個，耗魔相乘；實心格佔空位。拿起修飾時，蓋得到的技能亮起來。
    - 透明格的細節（Claude 暫定，試玩再調）：1 格的修飾整件都是透明格、不佔空位；2 格的是 1 透明 + 1 實心；羈絆只算實心格；小技能（原本的效果）這一步不能蓋，拿起修飾時不亮；技能搬走後，蓋在原處的修飾留在原地、失效；蓋了幾個寫在技能的角落。
  - **背包 = 主袋 + 接在四邊的袋子**，倉庫不生效（6 格，每格放一件、不管形狀，YangHsu 2026-11-04）。**主袋**放數值道具（攻擊力、攻速、生命、魔力、抗性、條件加成、常駐能力），放進去就生效。
  - **觸發袋接在哪一邊決定按鍵**：左 = 普攻、右 = 右鍵招式、下 = 不分按鍵；上方是**按鍵袋**（由左到右 = 數字鍵，開局 1 個、最多 3 個，技能欄只有 1~3 與 Q）。袋子可以沿著邊滑動；同一邊可以接好幾個。
  - **6 種觸發袋**：出手、命中、擊殺（接左 / 右）；受傷、翻滾、計時（接下方，計時的秒數寫在袋子上）。招架成功、蓄力這類武器專屬的不另做袋子，算右鍵的命中 / 出手（各武器怎麼算見改版構想的表）。
  - **技能、效果、修飾放在袋子裡**，主袋放了沒作用：
    - 技能（28 個）**不綁武器**，傷害照手上武器的基礎傷害算；放按鍵袋就是主動技能，放觸發袋就自動放。
    - 效果是原本的觸發道具改寫：只寫「發生什麼」，時機交給袋子、拿掉機率，重複的合併（對照在 `docs/道具清單.md`）。
    - 修飾（原本的輔助）作用在**同一袋**的所有效果，不再看相鄰。
    - 同一袋裡沒有順序，觸發時一起放；每個效果各自耗魔，魔力不夠時由左到右先放。命中袋同一袋 0.3 秒最多發動一次。
    - 只有普攻觸發左邊的袋子、只有右鍵招式觸發右邊的袋子；袋子放出來的效果與技能**不會再觸發袋子**（避免連鎖爆量）。
    - **有目標的袋子（命中、擊殺、受傷、招架）在目標身上發動**（YangHsu 2026-11-04）：範圍技能以目標為中心、指定落點的落在目標、連鎖從目標開始、投射物從命中點沿原方向射出（先打目標，能穿透的再打後面的怪；同時射出的扇形只有中間那支打得到目標）、位移技能自己朝目標移動；祝福、召喚留在自己身上。受傷袋的目標是打你的怪。沒有目標的袋子（翻滾、計時、出手、按鍵）照技能原本的放法。
  - **武器**決定普攻與右鍵的手感、基礎傷害，**不限制袋子數量**；限制靠主袋的邊長、魔力、袋子稀少。拿掉：武器格子、部位、印記格、寶石座、武器詞條。**副手與鍛造合成先保留**（Claude 2026-11-04 判斷：守墓騎士的劍盾、竊影者的雙匕首是主副手組合，拿掉要重做武器與職業；合成沒有詞條後只剩升稀有度），要不要拿掉再討論。
  - **大小**（Claude 暫定）：主袋 6 × 6（YangHsu 2026-11-04；四邊各接得下兩個小袋、上方接得下 3 個按鍵袋）；小袋 3 × 2（放得下最大的 4 格效果）、大袋 4 × 2、強化袋 3 × 2（傷害 ×1.5）、詛咒袋 5 × 2（受到傷害 +20%）、按鍵袋 2 × 2。
  - **羈絆 = 同色區塊**（C）：道具與效果格子的顏色是它的羈絆，同色上下左右連成一塊、**跨袋子也算**，看最大那塊幾格決定等級（4 / 8 / 12 格），取代件數門檻。星位（D）第一版不做。
  - **取得**：技能與效果常見（怪掉、寶箱、石棺、門）；袋子少，一大關約 3~5 個：開局職業送 1 個小袋、菁英怪掉跟牠招式有關的袋子、門的「袋子」獎勵、Boss 給大袋或倍率袋、祭壇 / 石棺偶爾開出詛咒袋（袋大但有缺點）。**鐵砧**改造袋子三選一（加大一格、換觸發、加倍率）或主袋 +1 行。
  - **開局**：主袋 + 按鍵袋 1（裝著職業的起始技能）+ 職業的小觸發袋（例：遊俠「左鍵命中袋 1×2」）。
  - **世界觀**：技能與效果是怪物的殘魂（怪掉跟自己有關的）、觸發袋是菁英怪的執念、鐵砧是鍛魂、背包道具是生前的遺物（顏色是沾染的元素）。
- **Build 機制（2026-10-30 許家慶決定，主機制「武器格子」；2026-11-04 起被上面的觸發袋取代，H 做完刪掉這段與表格裡的副手、合成、武器格子；細節與 Claude 暫定的數字在 [遊戲機制 artifact](https://claude.ai/artifact/HnZtmA1RX2mjUdZNNxrfAn)（原名武器格子））**：
  - 武器是一張格子圖，技能與道具都鑲在上面；放在哪個部位決定什麼時候發動（攻擊部位、末端、防禦部位、握柄、寶石座）。雙手武器格子比較多。
  - **魔力取代冷卻**（2026-11-02 許家慶決定）：寶石座技能與武器右鍵都不用冷卻，改成耗魔；所有職業有最大魔力與回魔兩項數值（先每個職業一樣），每招的耗魔依強度定。數字是 Claude 暫定（`docs/系統說明.md` §31）：耗魔 = 原本的冷卻秒數 × 5、回魔每秒 5 = 一招份（2026-11-02 許家慶試玩後從 10 減半），所以帶滿 4 個技能不再是 4 倍輸出，而是同一池魔力選要放哪一招。
  - **技能強度**（2026-10-31 YangHsu 決定；改成魔力後把「耗魔 ÷ 5」當冷卻秒數算）：技能放一次對每隻怪的傷害 = 這把武器普攻單體每秒傷害 × 冷卻 ÷ 3，也就是每個技能平均讓單體輸出多約 33%。範圍技能照「每隻」算，打一群自然更多。有暈眩或補血的功能型目標減半。有冷卻、有傷害的右鍵照同一條。評估時打一隻和打一群都要看：一群時算有打到的怪平均每隻吃多少（扇形、分裂的箭打一群時每隻只中一支），兩種都要接近目標；扇形的角度不為了數字改。想讓技能更重要就把 3 改小。實際數字看 `docs/平衡數字.md`（`node tools/release.mjs --balance` 產生）。
  - **武器強度**（2026-10-31 YangHsu 決定）：每把武器單拿時「普攻每秒 + 右鍵按冷卻攤平」打一隻的輸出分兩檔：近戰約每秒 30、遠程約 22（遠程安全，付約 0.75 倍的代價），±20%。打一群（12 隻）時是自己打一隻的 3~6 倍。只調基礎傷害（`base_damage`），攻速、範圍、箭袋這些手感不動；寶石座技能用基礎傷害算，會跟著等比例縮放。使用者同意過的絕對數字（盾反 24）跟著調倍率維持。**不能降傷害**：同一下打到的每隻都吃一樣的傷害，不做「前幾隻全額、後面遞減」；近戰揮擊打一群偏高（長劍、權杖約 11 倍）當作揮擊的特色保留，打一群偏低的往上拉（長弓的普攻箭穿過 2 隻）。**短弓例外**（2026-11-02 YangHsu 決定）：打一隻每秒是全部武器最高、箭不穿透，打一群偏低是它的代價（打一群靠右鍵散射）。**傷害數字是整數**：白裝每一招每一下（基礎傷害 × 倍率）都是整數，不出現 .5。數字看 `docs/平衡數字.md`。
  - 技能從遺物 3 選 1 拿到，放寶石座、用數字鍵 1~4 放（治療藥水改 Q）；第一版每種武器 3 個專屬技能（2026-10-30 許家慶照表同意，參考 POE2 依武器分，清單在 `docs/系統說明.md` §29）；每個技能寫明能用在哪些武器，或在不同武器上動作不同（旋轉：劍是旋風斬、弓是轉一圈往四周射箭）。
  - **羈絆**：每件道具屬於一個羈絆，湊到門檻啟動；門檻依羈絆的強度與泛用性不同（物理最好拿、要湊 10 件；幸運、神秘 4 件就滿但道具稀有）。鬼火參考 Sephiria 的「行星」（自動攻擊），骸骨參考「同伴」。
  - **傷害分屬性**（物理、火焰、冰霜、閃電、腐毒、神聖、暗影、秘術），每種有自己的狀態效果；怪物有相應的抗性，先只寫在圖鑑、遊戲裡不顯示。

## 操作與視野
- 能跳躍、能翻滾閃避（翻滾有極短的無敵時間）。
- **角色視野**：只看得到角色前方視野內的東西。視野外**完全看不見**怪物、怪物的攻擊、寶箱等可互動物件；地形看得到。多人時每人只看得到自己的視野，視野外連隊友都看不到（不共享視野）。例外：**倒地的隊友**在視野外也會在畫面邊緣出現紅色箭頭（寫剩幾秒），小地圖上是閃爍的紅點（使用者 2026-11-03：救援提示不夠，倒地 10 秒內要找得到人）。**小地圖根據探索畫**（YangHsu 2026-11-04）：只畫視野距離內、視線沒被牆擋住的格子，四周都算（不看面向），牆本身看得到；開局不預先畫邊界。
  - 例外（2026-10-26 使用者決定，特殊設計）：火把傭兵的火把（準備姿態舉著的、插在地上的）照亮的範圍全隊都看得到，就算不在自己的視野裡。
  - 數值（2026-10-23 決定）：前方 120°、18 單位（約到畫面邊緣）；身邊 4 單位不管方向都看得到（背後的攻擊快打到才出現）；牆擋視線，墓碑與高台不擋；視野外的地面變暗，但內外亮度差不要太大。2026-10-26 試玩後改：**側邊邊界要清楚**（漸層 0.3 單位），前方遠端的弧形寬 0.5（0.8）、背後（身邊一圈）的邊界模糊一點（1.0）；怪物、寶箱等進出視野時**淡入淡出**（像 Project Zomboid，0.2 秒），不是一下子出現 / 消失；寶箱、道具要中心進入視野才出現（露一角不算），怪物身體邊緣進來就出現。網頁版也要淡入淡出。
- **格擋**：盾牌只能擋「有方向的投射物」與「近戰攻擊」，而且只擋前方；持續傷害（毒霧）、Boss 砸地、範圍攻擊等一律擋不住。
  - 操作（2026-10-25 決定）：按住右鍵格擋、放開就放下，沒有冷卻；格擋中按左鍵招架（有冷卻）。招架判定內擋到攻擊 = 全額盾反；沒擋到也有傷害，但減半。按住右鍵時技能欄的左鍵改成「招架」。
- **傷害數字**（2026-10-25 決定）：實際傷害與血量保留小數（百分比加成才不會被四捨五入吃掉），畫面上不出現小數點：傷害數字四捨五入、血量無條件進位。
- **怪物**：沒有碰撞傷害，每種怪物都有自己的攻擊招式，打到玩家才會受傷。
- **怪物攻擊不畫紅圈**（2026-10-28 許家慶決定）：所有怪物與 Boss 的攻擊都不在地上畫預警圈或預警線，改用**預備動作、聲音與場景特效**（地板裂紋、塵土、影子、殘火、符文）讓玩家判斷。同一隻怪的不同招式，預備動作不能長得像，玩家多看幾次就能分辨要來哪一招、該怎麼躲。預備時間不因為拿掉紅圈而縮短。
  - 為什麼：全部用紅圈預告，最後只是單純的閃紅圈遊戲，整張圖都是紅圈，無聊又傷眼。
  - 玩家自己的技能也不畫落點圈（法杖奧術爆裂）：魔彈會被擋住提早爆炸，畫圈會讓玩家以為一定打在圈裡。
- **Boss 要有挑戰性**（2026-10-23 試玩後）：跑得快、出招快、招式範圍大；砸地往外一圈圈爆開（擊飛 + 緩速）、衝鋒撞到會暈眩、召喚混合骷髏戰士與弓手、直劈只能看動作（追蹤做一半，走位躲得開）；狂暴後招式進化（連衝、小怪衝撞、瞬移砸地，瞬移前要有明顯預兆、落地後只留零點幾秒反應）。
  - 砸地（2026-10-25 試玩後，2026-10-28 改）：三圈依序打、每圈間隔 0.5 秒（波往外比玩家跑得慢），往外跑或抓準時機跳都躲得掉。範圍不畫圈，改成地板裂紋從 Boss 腳下往外爬、縫裡透光，裂紋比每一圈爆開早 0.5 秒爬到，快炸的那一圈碎石跳動、越來越亮。
  - 四招預備動作（2026-10-28）：砸地 = 雙手合握筆直高舉、落地蹲低把劍插進地裡；衝鋒 = 壓低前傾、後腳刨地兩下揚起塵土；召喚 = 雙臂往兩側張開、仰頭；直劈 = 單手舉劍過頭、身體後仰。
- **職業與武器手感**：法杖像法師，普攻不是重點（攻速慢）；遠程武器分輕重型（2026-10-26 使用者決定）：**輕型**（法杖、短弓）普攻不擊退、不讓怪物踉蹌；**重型**（長弓）攻速慢，普攻可擊退。武器有自己的基礎數值（攻擊力、攻速、範圍），稀有度越高數字越高。
- **沒有安全區**（2026-10-23）：玩家去得了的地方怪物都去得了，怪物只是比玩家多花一點時間上去（近戰怪會跳上高台，起跳前多蹲一下）；遠程怪打得到高台上的玩家。被牆擋住的怪會繞路。
- **地圖**（2026-10-23）：第 1 層先做 A「環形墓園」；B、C、D 之後也做，每場隨機出現一張（草圖在 `mockups/graveyard_map.html`）。「每層 5 分鐘走完」先不管，實際玩過再說。事件中的怪可以直接在視野內從地板冒出來，所以入口少（例如只有北門）不是問題。

## 調整時的判斷依據

- **難度**：新手第一次挑戰應該通不了關。調整時以「沒有遊戲外成長的新手」和「成長升滿的熟練玩家」兩種情況分別評估，數值要寫出實測結果（存活秒數、到達波次、通關率）。
- **戰鬥**：三個重點不能為了其中一個犧牲另一個。例如加強打擊感時，不能讓走位變得不重要；開局不能讓玩家無腦清怪，build 成形後才可以。
- **回血**：自然回血慢、受傷後一段時間不回（2026-10-29 許家慶決定：回太快讓遊戲太簡單）；戰鬥中補血靠藥水與道具。
- **build 與職業**：新增武器、技能、職業時，要能形成「不同的通關方式」，不只是數值換皮。
- **道具**：越強的道具占越多格；高稀有度道具每格要比較划算，否則玩家只會塞滿低稀有度道具。
