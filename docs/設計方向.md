# 設計方向

> 修改核心玩法（戰鬥手感、敵人行為、波次節奏、數值平衡、操作方式）前必讀。內容由使用者決定，AI 不可自行修改；「未定」的項目遇到時先問使用者。
> 細節還沒定案的點子在 `docs/想法清單.md`；道具草稿在 `docs/道具清單.md`。

## 一場遊戲的流程
- 第 1 層：地面的墓地（設計過的固定地圖，A~D 四張隨機一張，見「操作與視野」的地圖）。之後每層是地下陵墓。測試期共 5 層。
- 地圖有設計過，怪物一群一群分散在地圖上；每層的資源與怪物數量有限。
- **去下一層的事件**：每層都有，第 1 層是「挖墳」，之後每層換成不同的形式（可以往惡搞方向），但本質相同：
  - 有人在定點「累積進度 %」，累積時什麼都不能做，可以隨時開始、隨時取消；沒人累積時進度會緩慢下降。
  - 被打**不會中斷**累積（超硬的坦克 build 可以扛著傷害直接累積完）。
  - 事件開始後**先只出現一隻 Boss**；Boss 倒下後其他怪物才開始不斷冒出，而且越來越多、越來越難（稀有怪變多、難的怪變多、數值變高）；拖太久就會害死玩家（2026-10-25 試玩後改：原本 Boss 與怪潮同時來，怪太多太快，沒空打 Boss、更沒空挖）。
  - Boss 戰期間照樣可以挖；Boss 不打死也能下去；打死有獎勵（武器或道具，未定）。
  - 所有人的畫面上方都有明顯的挖墳進度條。
  - 所有玩家都下去才開始下一層。單人時怪物生成較少。
- **難度**：沒有全場時間難度。每層有固定的基礎難度（例如第 1 層 0、第 2 層 10），怪潮開始（Boss 倒下）後難度從該層基礎值一路往上，可以超過下一層的基礎值。到了下一層一律從該層基礎值重新開始。
  - 選角畫面選難度（2026-10-27 使用者決定）：簡單 / 普通 / 困難，只改怪潮開始後難度上升的速度 ×0.75 / ×1 / ×1.5，其他不動；多人由房主選。
  - 高風險高回報：玩家可以開事件後故意不走，多賺錢、多拚武器掉落。
  - 數值（2026-10-23 決定，2026-10-25 改）：挖墳一人 60 秒、沒人挖每秒 −0.2%（原本 −1%，使用者要求大幅調低）；怪潮生怪 2026-10-25 再放慢（清怪比不上生怪、完全挖不了）：間隔 5 → 1 秒、每 50 點難度多 1 隻；難度線性無上限（怪潮開始後每秒 +1，約 2 分鐘還撐得住、待到 4~5 分鐘幾乎必死）；每層基礎難度 +10；Boss 必掉武器 + 一個大寶箱機率的道具。

## 玩家拿到的東西
| | 武器 | 道具 |
|---|---|---|
| 取得 | 殺怪機率掉落（多人時只掉一把，先撿先得） | 殺怪收集靈魂（多人共用），花靈魂開地圖上的祭壇 / 石棺（2026-10-26 使用者決定：盜墓主題，遊戲裡不用錢買寶箱） |
| 稀有度 | 白綠藍紫橘 | 白綠藍紫橘 |
| 稀有度差別 | 白色無詞條，每高一級多一條隨機詞條 | 越稀有越強，占的格子也越多 |
| 特殊規則 | 裝備欄 2 把（X / 滾輪切換，只有手上那把的詞條生效）；背包也能放武器但沒效果；兩把**同一種、同稀有度**拖在一起合成高一級，詞條重新產生（2026-10-23 決定） | 放進背包就生效 |
- **靈魂與祭壇 / 石棺數值（D3，Claude 暫定，試玩後再調）**：2026-10-26 使用者決定局內的錢改叫**靈魂**、小寶箱 / 大寶箱改成**祭壇 / 石棺**，數值照舊。小怪 2、Boss 30 靈魂（2026-10-25 從 5 / 50 調低），召喚出來的怪不給；祭壇 25、石棺 60；
  - 寶箱比錢多（2026-10-25 使用者決定）：清完地圖全部的怪也開不完全部寶箱。地圖 A 開場隨機放 12 小 + 4 大（總價 540），開場怪群全清約 248~444 金。多人每多 1 人寶箱數量與殺怪金錢 +50%（不是一人一倍）。
  - 小箱小箱 白 70 / 綠 25 / 藍 5 %，大箱 綠 50 / 藍 35 / 紫 13 / 橘 2 %。寶箱開出的道具掉在地上，按 F 撿起（多人先撿先得）。
- **背包**：一格一格的空間，道具形狀不規則、可以旋轉，空間管理是策略的一環。道具越強占越多格（平衡做法見 `道具清單.md`）。
- **職業與武器**：不限制。職業 = 基礎數值 + 起始武器 + 職業被動（2026-10-26 使用者決定）：所有武器都從怪物身上掉，起始職業只決定開局拿哪一把；**職業被動跟著職業走、不綁武器**（例如守墓騎士換弓也還是坦）。之後的天賦再加在上面。草案：[職業構想](https://claude.ai/artifact/Uh213GXWMsG87G4kGJBQnf)、[武器構想](https://claude.ai/artifact/4n5VEg55cBfqDnGd6jtMD8)。

## 遊戲外成長
- 遊戲內賺一種帶得出去的貨幣，用來買各職業的天賦或技能。
  - 這個貨幣是**金幣**（2026-10-26 使用者決定：盜墓的目的就是把錢帶出來）。獲得量與方式使用者還在構思，先暫定：
    - 每過一關給一點，越後面的關卡越多（第一關最少）；之後每關中間做一個「開寶箱噴錢」的小動畫。暫定（Claude）：過第 N 層 5 × N。
    - 殺怪、殺 Boss 有極低機率掉 1 枚（參考雨中冒險 2 怪物掉的藍色月幣）。暫定（Claude）：小怪 0.3%、Boss 3%，走過去自動撿。
    - 多人時全員各拿一份（Claude 暫定）。
- 完成成就解鎖更多職業、武器、裝備。

## 操作與視野
- 能跳躍、能翻滾閃避（翻滾有極短的無敵時間）。
- **角色視野**：只看得到角色前方視野內的東西。視野外**完全看不見**怪物、怪物的攻擊、寶箱等可互動物件；地形看得到。多人時每人只看得到自己的視野，視野外連隊友都看不到（不共享視野）。
  - 例外（2026-10-26 使用者決定，特殊設計）：火把傭兵的火把（準備姿態舉著的、插在地上的）照亮的範圍全隊都看得到，就算不在自己的視野裡。
  - 數值（2026-10-23 決定）：前方 120°、18 單位（約到畫面邊緣）；身邊 4 單位不管方向都看得到（背後的攻擊快打到才出現）；牆擋視線，墓碑與高台不擋；視野外的地面變暗，但內外亮度差不要太大。2026-10-26 試玩後改：**側邊邊界要清楚**（漸層 0.3 單位），前方遠端的弧形寬 0.5（0.8）、背後（身邊一圈）的邊界模糊一點（1.0）；怪物、寶箱等進出視野時**淡入淡出**（像 Project Zomboid，0.2 秒），不是一下子出現 / 消失；寶箱、道具要中心進入視野才出現（露一角不算），怪物身體邊緣進來就出現。網頁版也要淡入淡出。
- **格擋**：盾牌只能擋「有方向的投射物」與「近戰攻擊」，而且只擋前方；持續傷害（毒霧）、Boss 砸地、紅圈範圍攻擊等一律擋不住。
  - 操作（2026-10-25 決定）：按住右鍵格擋、放開就放下，沒有冷卻；格擋中按左鍵招架（有冷卻）。招架判定內擋到攻擊 = 全額盾反；沒擋到也有傷害，但減半。按住右鍵時技能欄的左鍵改成「招架」。
- **傷害數字**（2026-10-25 決定）：實際傷害與血量保留小數（百分比加成才不會被四捨五入吃掉），畫面上不出現小數點：傷害數字四捨五入、血量無條件進位。
- **怪物**：沒有碰撞傷害，每種怪物都有自己的攻擊招式，打到玩家才會受傷。
- **Boss 要有挑戰性**（2026-10-23 試玩後）：跑得快、出招快、招式範圍大；砸地紅圈往外擴散（擊飛 + 緩速）、衝鋒撞到會暈眩、召喚混合骷髏戰士與弓手、直劈沒有紅圈只能看動作（追蹤做一半，走位躲得開）；狂暴後招式進化（連衝、小怪衝撞、瞬移砸地，瞬移前要有明顯預警、落地後只留零點幾秒反應）。
  - 砸地（2026-10-25 試玩後）：攻擊範圍畫成實心圈；三圈依序打、每圈間隔 0.5 秒（波往外比玩家跑得慢），往外跑或抓準時機跳都躲得掉。
- **職業與武器手感**：法杖像法師，普攻不是重點（攻速慢）；遠程武器分輕重型（2026-10-26 使用者決定）：**輕型**（法杖、短弓）普攻不擊退、不讓怪物踉蹌；**重型**（長弓）攻速慢，普攻可擊退。武器有自己的基礎數值（攻擊力、攻速、範圍），稀有度越高數字越高。
- **沒有安全區**（2026-10-23）：玩家去得了的地方怪物都去得了，怪物只是比玩家多花一點時間上去（近戰怪會跳上高台，起跳前多蹲一下）；遠程怪打得到高台上的玩家。被牆擋住的怪會繞路。
- **地圖**（2026-10-23）：第 1 層先做 A「環形墓園」；B、C、D 之後也做，每場隨機出現一張（草圖在 `mockups/graveyard_map.html`）。「每層 5 分鐘走完」先不管，實際玩過再說。事件中的怪可以直接在視野內從地板冒出來，所以入口少（例如只有北門）不是問題。

## 多人
- 倒下：先進入假死一段時間，隊友靠近按互動可以救起（類似槍火重生）。
- 超過時間救不回來：屍體要裝進背包（占 2 × 3 = 6 格，Claude 暫定，約背包的 1/8）帶到下一層，該玩家在下一層變成冤魂出現，打倒冤魂就會復活，背包裡的屍體同時消失。
- 全員倒下就輸掉這一局（除非有復活類道具）。
- **誤傷隊友：開啟**。
- 惡搞元素：之後再想。

## 調整時的判斷依據

- **難度**：新手第一次挑戰應該通不了關。調整時以「沒有遊戲外成長的新手」和「成長升滿的熟練玩家」兩種情況分別評估，數值要寫出實測結果（存活秒數、到達波次、通關率）。
- **戰鬥**：三個重點不能為了其中一個犧牲另一個。例如加強割草感時，不能讓走位變得不重要。
- **build 與職業**：新增武器、技能、職業時，要能形成「不同的通關方式」，不只是數值換皮。
- **道具**：越強的道具占越多格；高稀有度道具每格要比較划算，否則玩家只會塞滿低稀有度道具。
