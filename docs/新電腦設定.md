# 新電腦設定

在新電腦第一次使用本專案時照著做一次。之後每個新對話，Claude 會依 `CLAUDE.md` 第 0 節自動 `git pull`。

## 1. 安裝工具
- **Claude 桌面版**：從 https://claude.ai/download 下載安裝，登入同一個帳號。
- **Git、Node、GitHub CLI**：在 PowerShell 執行：

```powershell
winget install --id Git.Git -e; winget install --id OpenJS.NodeJS.LTS -e; winget install --id GitHub.cli -e
```

裝完**關掉 PowerShell 再開一個新的**，新裝的指令才找得到。

## 2. 登入 GitHub
```powershell
gh auth login --web
```
- 問 `Authenticate Git with your GitHub credentials?` 時按 Enter（Yes）。
- 畫面出現 8 碼驗證碼後按 Enter 開瀏覽器，登入 GitHub、輸入驗證碼、按 Authorize。
- 出現 `Logged in as alex86106pig` 就完成。

## 3. 下載專案
到想放專案的資料夾執行：
```powershell
git clone https://github.com/alex86106pig/Cubeborn.git
```

## 4. 用 Claude 開啟專案
在 Claude 桌面版的 Code 分頁開啟剛下載的 `Cubeborn` 資料夾，跟 Claude 說「執行 `npm install`」，裝好 `check.js` 需要的套件（每台電腦只需一次）。

## 5. 確認
請 Claude 執行 `node check.js`，看到全部通過就設定完成。

## 公司電腦
先確認公司是否允許安裝軟體、登入個人 GitHub 帳號、使用 Claude。

## 換電腦的習慣
- 離開一台電腦前：跟 Claude 說「推上去」。
- 到另一台電腦：開新對話，Claude 會自動 pull 最新內容。
