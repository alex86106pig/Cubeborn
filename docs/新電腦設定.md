# 新電腦設定

在新電腦第一次使用本專案時照著做一次。之後每個新對話，Claude 會依 `CLAUDE.md` 第 0 節自動 `git pull`。

## 1. 安裝工具
- **Claude 桌面版**：從 https://claude.ai/download 下載安裝，登入同一個帳號。
- **Git、Node（必裝：檢查與推送都用 `tools/release.mjs`）、GitHub CLI**：Windows 在 PowerShell 執行下面的指令；Mac 用 Homebrew（`brew install git node gh`）或官網安裝檔。

```powershell
winget install --id Git.Git -e; winget install --id OpenJS.NodeJS.LTS -e; winget install --id GitHub.cli -e
```

裝完**關掉 PowerShell 再開一個新的**，新裝的指令才找得到。

## 2. 登入 GitHub
```powershell
gh auth login --web
```
- 問 `Authenticate Git with your GitHub credentials?` 時按 Enter（Yes）。
- 畫面出現 8 碼驗證碼後按 Enter 開瀏覽器，登入 GitHub、輸入驗證碼、按 Authorize。
- 出現 `Logged in as alex86106pig` 就完成。

## 3. 下載專案
到想放專案的資料夾執行：
```powershell
git clone https://github.com/alex86106pig/Cubeborn.git
```

## 4. 用 Claude 開啟專案
在 Claude 桌面版的 Code 分頁開啟剛下載的 `Cubeborn` 資料夾。（舊網頁版在 `legacy/`，要動它時才需要在該資料夾執行 `npm install`。）

## 5. 安裝 Godot（遊戲正式版用）
- 到 https://godotengine.org/download/windows/ 下載 **Godot Engine 4.7.2 普通版**（不要下載 .NET 版），解壓縮即可使用，不需安裝。
- 放在哪個資料夾都可以，下一步會告訴 Claude 路徑。
- 在 Godot 編輯器選「匯入」，選本專案的 `godot/project.godot`。

## 5.1 安裝網頁版匯出模板（本機測網頁版用）
- 下載 https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz （約 1.28 GB，是 zip 檔）。
- 解壓縮後，只把 `templates/` 裡的 `version.txt` 與 `web_*` 檔案放進：Windows `%APPDATA%\Godot\export_templates\4.7.2.stable\`；Mac `~/Library/Application Support/Godot/export_templates/4.7.2.stable/`。其餘檔案和下載的 .tpz 可以刪掉。
- 也可以請 Claude 代為下載安裝。裝好後 `node tools/release.mjs --web` 會匯出網頁版並開 http://localhost:8060 ；`--perf` 用 Google Chrome 在背景量網頁版效能（Chrome 裝在預設位置以外時，路徑寫進 `CLAUDE.local.md`）。

## 5.2 Mac 才要：桌面版 WebRTC 程式庫
- repo 的 `godot/addons/webrtc_native` 只有 Windows / Linux 版；Mac 沒裝的話，桌面版不能用房號連線，`check.gd` 有 3 項 WebRTC 檢查不會過。
- 在專案根目錄執行（從 Godot 官方 webrtc-native 1.2.2 只解出 macOS 的兩個 `.framework`，約 10 MB，不進版控）：

```bash
gh release download 1.2.2-stable -R godotengine/webrtc-native -p godot-extension-webrtc_native.zip -D /tmp --clobber
unzip -o /tmp/godot-extension-webrtc_native.zip 'addons/webrtc_native/lib/libwebrtc_native.macos.*' -d godot/
```

- 也可以請 Claude 代為下載安裝。版本要和 `webrtc_native.gdextension` 開頭寫的一致。

## 6. 建立本機設定
跟 Claude 說「這台電腦叫 ＿＿＿，Godot 放在 ＿＿＿」。名稱自己取（例如 alex_work），只是辨識用。Claude 會建立 `CLAUDE.local.md` 記下這台的路徑與硬體，這個檔案不會推上 GitHub（見 `CLAUDE.md` 3.3）。

## 7. 確認
請 Claude 執行 Godot 自動檢查（`node tools/release.mjs --check`），看到全部通過就設定完成。
網頁版已凍結，`legacy/` 的 `npm install` 只有要動到網頁版時才需要。

## 8. 選做：commit 不帶 Claude 署名
在專案的 `.claude/settings.local.json`（不進版控）加 `"attribution": { "commit": "", "pr": "" }`。

## 公司電腦
先確認公司是否允許安裝軟體、登入個人 GitHub 帳號、使用 Claude。

## 換電腦的習慣
- 離開一台電腦前：跟 Claude 說「推上去」。
- 到另一台電腦：開新對話，Claude 會自動 pull 最新內容。
