# 動作參考（真實動作的數字）

角色動作（`godot/view/body_pose.gd`、`animator.gd`、`skill_poses.gd`、`enemy_animator.gd`）照這裡的真實動作做。改常數時先對照這裡的範圍。
檢查「角色骨架與動作」會擋步態的膝蓋、髖部角度與腳踩地；量到的數字在 `godot/tests/check_last.log`。

## 骨架

- 每個角色：上臂 → 手肘 → 前臂 → 拳頭；大腿 → 膝蓋 → 小腿 → 腳底（腳伸直時腳底在地上）。手肘只往前彎、膝蓋只往後彎（單軸的鉸鏈）。
- 四足（屍犬）：前腳的中間關節是腕關節，往前凸（抬腳時腳掌往後收）；後腳是跗關節，往後凸。蜘蛛、甲蟲的腳關節往上拱，腳尖撐在身體外側。

## 步態（走、跑）

| 項目 | 真實 | 遊戲用的 | 遊戲量到 |
|---|---|---|---|
| 走 → 跑的分界 | Froude 數 v²/(g·腿長) ≈ 0.5 | 0.4 ~ 3.0 之間漸變（`RUN_FROUDE`） | 玩家移速 6.5：Fr 4.5 = 全跑；腐屍 5.6 也是跑、拖步 |
| 步幅（左右各一步 ÷ 腿長） | 2.3 × Fr^0.3（Alexander，人與四足都適用） | 同（`STRIDE_K`、`STRIDE_EXP`），夾在 1.0 ~ 4.2 | 走 1.6/秒：1.48；跑 6.5/秒：3.44 |
| 一隻腳踩在地上的比例 | 走 ~0.6、跑 0.3~0.4 | 0.62 → 0.33（`DUTY_WALK` / `DUTY_RUN`） | |
| 走路踩地初期膝蓋 | ~15° | — | 14° |
| 走路擺盪期膝蓋最大 | 40~60°（約 60°） | 腳抬 0.15 腿長（`LIFT_WALK`） | 66° |
| 走路髖部 | 腳跟著地屈 ~30°、離地伸 ~10° | 踩地範圍前 60% 後 40%（`STANCE_FRONT`） | 屈 41°、伸 7° |
| 跑步擺盪期膝蓋最大 | 90~125° | 腳先往後上踢 0.42 腿長（`LIFT_RUN`） | 115° |
| 跑步髖部往前抬 | 55°（跑）~80°（衝刺） | — | 65° |
| 跑步踩地中段膝蓋 | ~40° 吸收衝擊 | 髖部降到 0.93 腿長（`HIP_RUN`） | 56° |
| 手臂擺動 | 跟對側的腳同方向；跑步手肘約 90° | 走 ±17°、手肘 17°；跑 ±43°、手肘 86° | |
| 落地 | 膝蓋彎曲至少 45°（落地篩檢標準） | 落地 0.18 秒內髖部沉 0.16 腿長 | |

- 沒有腳掌：真人腳掌從腳跟滾到腳尖，分掉一部分前後距離；這裡直接把踩地的移動距離縮成 0.8（`FOOT_ROLL`），踩地的腳會在地上滑一點點。
- 腐屍拖著腳（`ZOMBIE_SHUFFLE` 0.55）：步子小、抬腳低，踩得快一點腳才不會滑。

## 招式

- **揮砍**（劍、權杖、骷髏的刀）：發力順序是下半身 → 轉腰 → 肩膀 → 手肘伸直，打中的瞬間手臂最直。蓄力時腰往反方向扭、手肘收起；收招手肘回彎。前腳是持劍手的對側腳。
- **刺 / 弓步**（擊劍）：持劍手先伸直，後腳再蹬；前腳往前踏到膝蓋約直角，後腿蹬直；後手往後伸平衡。前腳膝蓋先彎再伸、後膝的活動量越大越快。
- **拉弓**（反曲弓教學）：側身讓弓手的肩膀對靶；弓手伸直但手肘不鎖死；拉弦的手肘抬到箭的直線上、和地面約平行，靠背部的肌肉出力；拉弦手拉到下巴，放箭後順著往後彈。
- **鏟土**：彎膝蓋、背打直，不從腰彎（真人軀幹屈 40~50°）；甩出去時整個身體轉過去、往甩的方向踏一步，不扭腰。
- **砸地 / 舉過頭**：舉起時手肘彎著蓄力（前臂在頭後），往下砸時手肘打直、膝蓋跟著蹲，重心往下。
- **跳躍**：蹲下蓄力時膝蓋約 90~100°；落地膝蓋要彎，至少 45°。
