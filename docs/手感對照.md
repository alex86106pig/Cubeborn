# 手感對照：網頁版 vs Godot 版

> v0.12.1 量測。數字都由 `godot/tests/check.gd` 自動檢查，跑 headless 就會重新量一次（輸出最後的「手感量測」段落）。
> 結論：**數值與規則層面兩版一致**；剩下的只有「實際玩起來的感覺」要由使用者在桌機試玩確認。

## 1. 資料逐欄比對（自動）
`tools/dump_web_defs.mjs` 把網頁版 `legacy/src/` 的設定、武器、敵人、技能、波次匯出成 `godot/tests/web_defs.json`，
`check.gd` 逐欄比對 Godot 的 `core/config.gd` 與 `defs/`：**217 個欄位全部相同**（數字、顏色、陣列、名稱）。
網頁版資料若有改動，重跑 `node tools/dump_web_defs.mjs` 再跑檢查即可。

## 2. 網頁版寫死在程式裡的數字（人工核對）
Godot 版把這些數字搬進了資料表；逐一到網頁版原始碼找出原值，**全部相同**：

| 類別 | Godot 欄位 = 數值 | 網頁版出處 |
|---|---|---|
| 主迴圈 | `HIT_STOP_TIME_SCALE` 0.05、`victory_delay` 2.2、勝利停頓 0.25、震動 0.8 / 0.6 | `Game.js` |
| 生成 | 開波後第一隻 0.6 秒（Boss 波 1.2）、找生成點 20 次、離邊緣 2、Boss 離中央 8 | `Spawner.js` |
| 戰鬥 | 命中震動 0.15 秒、爆炸震動 0.3 秒、投射物高度 1.25、扇形貼身必中距離 半徑 + 0.3 | `Combat.js`、`Projectile.js` |
| 玩家 | 硬直移速 ×0.4、道具動作 0.18 秒、受傷震動 0.25 / 0.2 | `playerStates.js`、`Player.js` |
| 劍盾 | 第三段：傷害 ×1.8、擊退與停頓 ×1.8、震動 ×2.5、範圍 ×1.25、後搖 ×1.6；盾擊質量 8、判定中心前方 0.5 | `weaponBehaviors.js` |
| 法杖 | 投射物出生點前方 0.6（奧術爆裂射程扣掉 0.6） | `weaponBehaviors.js` |
| 小怪 | 接觸寬容 0.15、揮擊動畫 0.3 秒 | `Enemy.js`、`MeleeEnemy.js` |
| 弓手 | 射擊距離上限 +3、橫移 1.2~2.6 秒 ×0.6、瞄準前 75% 追蹤 ×1.5 轉速、首射 0.8~2 秒、射擊間隔 ×0.8~1.25、箭擊退 6、出箭點前方 0.7 | `RangedEnemy.js` |
| Boss | 出場震動 0.4、出招間隔 0.4、開場 CD 衝鋒 3 / 召喚 2；重砸停頓 0.06、震動 0.7 / 0.35；衝鋒命中 +0.3、停頓 0.06、震動 0.4、撞牆邊距 0.05、撞牆震動 0.6 / 0.35；召喚角度 0.9、距離 2.5、離邊緣 1.5；狂暴震動 0.5 / 0.4 | `Boss.js` |

唯一不同（只影響畫面）：弓手的箭在網頁版飛在「弓手身高 × 0.6 ≈ 1.17」，Godot 原本畫在 1.25。v0.12.1 已改成相同。
