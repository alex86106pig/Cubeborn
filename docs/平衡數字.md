# 平衡數字

> `node tools/release.mjs --balance` 產生，不要手改；調完 `defs/` 的數字重跑。版本 v0.55.2。
> 條件：白裝、技能 1 級、沒有道具與羈絆、測試場地（不含挖墳難度倍率）。假人抗性清空、站著不動、不會死。
