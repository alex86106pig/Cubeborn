## 1. 進場與地圖（D1、D2）
- [ ] 走完整張地圖 A，沒有卡牆
- [ ] 站上高台時，怪物會先蹲 0.25 秒（Claude）再跳上來，這個手感可以嗎
- [ ] 5 波的怪在離你 8~18 單位的地方出現，在大地圖上合適嗎
- [ ] 3.0 高的牆會擋住牆後約 3.6 單位：角色走到牆後被擋住時，剪影看得清楚嗎（見第 8 節）
- [ ] 地圖在畫面上是菱形；想不想讓牆和螢幕邊平行（要改相機方位角）
- [ ] 視野外變暗、牆後隱藏的範圍可以嗎（牆後的地面目前沒有變暗）
- [ ] 視野邊界清楚了嗎（漸層 0.3）；怪物進視野淡入 0.3 秒、離開淡出 0.5 秒（Claude 暫定）的速度可以嗎；寶箱露一角不出現、中心進來才出現自然嗎；電腦版與網頁版都看一次（淡入淡出改材質，網頁版第一次淡出會不會頓一下）

- [ ] 主選單：開場的單人 / 多人 / 離開、多人頁開房加入與返回、Esc 選單的「回主選單」用起來順嗎；朋友第一次打開知道要按哪裡嗎

## 2. 戰鬥操作
- [ ] 格擋 120°、盾反 3.5 單位 / 180°：格擋時的扇形夠明顯嗎
- [ ] 按住右鍵格擋、格擋中左鍵招架：招架判定 0.2 秒、冷卻 4 秒、沒擋到時盾擊 12.5（顯示 13）合適嗎（Claude 沿用舊數值）；技能欄左鍵換成「招架」看得懂嗎
- [ ] 新手提示框（背包與合成、挖墳與出口、戰鬥操作）：文字看得懂嗎，出現的時機對嗎（暫停選單可以重設提示）
- [ ] 特效：死亡碎骨、暈眩星星、召喚、治療 / 盾反的環、怪物爬出時的塵土都正常嗎；第一次出現時會不會卡一下
