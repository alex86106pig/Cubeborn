> 從 `docs/進度.md` 搬來的「還沒人玩過」項目，照試玩時遇到的順序排。玩的時候逐條打勾 `[x]`，有意見直接寫在該條後面（或口頭告訴 Claude）。
> 打勾後由 Claude 把結論移到 CHANGELOG / `docs/手感對照.md`，再把該條刪掉；全部刪完這份就可以刪了。

## D7 記錄表（第 1 層完整驗收）
目標：單人從進場玩到下一層入口，5 分鐘內走得完；兩人連線也走得完。結果之後抄進 `docs/手感對照.md`。
v0.34.0 起結算畫面會顯示遊玩紀錄（擊殺、受到的傷害、被看不見的攻擊 %、被誰打倒），照抄就好，可以直接拍照給 Claude。
「被看不見的 %」用來確認設計衝突：割草清怪 + 只看得到前方 120°，會不會常被看不見的東西打死。

## 1. 進場與地圖（D1、D2）
- [ ] 走完整張地圖 A，沒有卡牆
- [ ] 站上高台時，怪物會先蹲 0.25 秒（Claude）再跳上來，這個手感可以嗎
- [ ] 5 波的怪在離你 8~18 單位的地方出現，在大地圖上合適嗎
- [ ] 3.0 高的牆會擋住牆後約 3.6 單位：角色走到牆後被擋住時，剪影看得清楚嗎（見第 8 節）
- [ ] 地圖在畫面上是菱形；想不想讓牆和螢幕邊平行（要改相機方位角）
- [ ] 視野外變暗、牆後隱藏的範圍可以嗎（牆後的地面目前沒有變暗）

## 2. 戰鬥操作（v0.23.0、v0.31.0）
- [ ] 格擋 120°、右鍵取消、盾反 3.5 單位 / 180°：格擋時的扇形夠明顯嗎
- [ ] 新手提示框（背包與合成、挖墳與出口、戰鬥操作）：文字看得懂嗎，出現的時機對嗎（暫停選單可以重設提示）
- [ ] 特效：死亡碎骨、暈眩星星、召喚、疾跑殘影、治療 / 盾反的環、怪物爬出時的塵土都正常嗎；第一次出現時會不會卡一下

## 3. 怪物稀有度與怪群（D5）
- [ ] 魔法 / 稀有怪的詞條強度、怪群數量與分布合適嗎（名字表是 Claude 擬的）
- [ ] 魔法 / 稀有怪的金幣與掉寶目前**沒有加成**：要不要加
- [ ] 王族墓旁邊有一群怪（怪群沒有避開挖墳點），走進去會先打一場，合不合適

## 4. 寶箱、背包、武器（D3、D4）
- [ ] 寶箱價格與稀有度機率（Claude）合適嗎
- [ ] 道具會掉在「寶箱往你的方向」：站太近時道具被角色擋住，看得到嗎
- [ ] 背包裡相鄰的同色道具沒有整塊外框，看起來連在一起，會分不清嗎
- [ ] 把武器拖到另一把武器上合成，操作順手嗎
- [ ] 武器詞條清單、「只有手上那把武器生效」（Claude）合適嗎

## 5. 道具第一批 8 個（v0.33.0）
單機可以按 F4 直接把道具放進背包、F5 清空。數字都在 `ItemDefs.PROCS`（Claude）。
- [ ] 獵犬項圈：對滿血敵人傷害 +25%
- [ ] 狂戰士護符：生命低於 35% 時傷害 +25%
- [ ] 戰鼓：擊殺後 3 秒攻速 +30%
- [ ] 吸魂鐮：擊殺回復 3% 最大生命
- [ ] 火藥包：擊殺時 10% 機率小爆炸（半徑 2.5）
- [ ] 雷鳴符文：命中 10% 機率連鎖閃電，最多跳 3 隻
- [ ] 淬毒刀刃：命中 15% 機率中毒，怪物變綠（顏色會不會太重）
- [ ] 霜之心：命中 10% 機率冰凍 1.5 秒，怪物變藍（顏色會不會太重）

## 6. 挖墳事件與下一層（D6）
- [ ] 挖墳時的難度曲線：生怪間隔 3 → 0.8 秒、每批從 2 隻起、每 20 點進度 +1 隻、同時最多 120 隻（Claude）
- [ ] 目標「撐 2 分鐘守得住、4~5 分鐘一定會死」：實際撐了幾分鐘
- [ ] 冤魂（生命 150、傷害 14，Claude）強度合適嗎
- [ ] 挖墳時你的身體會把怪推開（不會被擠走），感覺可以嗎
- [ ] 出口出現、走進去換到下一層的流程順嗎
