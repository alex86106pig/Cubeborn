# Cubeborn 連線試玩說明

有兩種玩法，最多 4 人：
- **網頁版（最簡單）**：大家都用瀏覽器開網站，房主開房、其他人輸入 4 碼房號，不用下載、不用裝東西。見第 0 節。
- **Windows 版**：下載遊戲，不在同一個家裡的話再用「虛擬區網」軟體連在一起。見第 1~4 節。

網頁版和 Windows 版不能混在一起玩。

## 0. 網頁版連線
1. 每個人用電腦的瀏覽器（Chrome / Edge / Firefox）開 https://alex86106pig.github.io/Cubeborn/ 。
2. **房主**：按 `Esc` →「開房（網路）」，選單會顯示 4 碼房號，把房號告訴大家。
3. **其他人**：按 `Esc` → 在「房號」欄位輸入那 4 碼 →「加入」。
4. 到齊後房主按「開始遊戲」。
5. **房主不要切換分頁、不要縮小視窗**：瀏覽器會把背景分頁停掉，所有人都會卡住。
6. 連不上時：確認房號沒打錯、房主還開著房間；少數公司或學校的網路會擋直連，換個網路（例如手機熱點）再試。配對用的是免費的公共伺服器，偶爾會掛，等一下再試。

## 1. 下載遊戲（每個人都要）
1. 到 https://github.com/alex86106pig/Cubeborn/releases ，下載最新版的 `Cubeborn-vX.Y.Z-windows.zip`。
2. 解壓縮到任何資料夾，執行 `Cubeborn.exe`。
3. 第一次執行如果跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」（遊戲沒有數位簽章，所以會跳這個警告）。
4. **每個人的版本要一樣**，版本號在遊戲畫面右上角。

## 2. 組虛擬區網（不在同一個家裡才需要）
三選一，全部的人用同一套就好：
- **Radmin VPN**（最簡單，免註冊）：一個人「建立網路」設名稱和密碼，其他人「加入網路」輸入同樣的名稱和密碼。每個人名字旁邊會顯示一個 `26.x.x.x` 的 IP。
- **ZeroTier**：一個人在官網建一個網路，把網路 ID 給大家加入，建的人要在官網勾選允許每一台。
- **Tailscale**：用 Google 等帳號登入；建的人把其他人邀請進同一個網路。

同一個家裡、連同一台路由器的話，跳過這步，直接用區網 IP（`192.168.x.x`）。

## 3. 開房與加入
1. **房主**：進遊戲後按 `Esc` 開選單 →「開房（區網）」。
2. 第一次開房時 Windows 會問要不要允許網路存取：**私人網路、公用網路都打勾**再按允許（虛擬區網常被當成公用網路，沒勾到朋友就連不進來）。
3. **其他人**：按 `Esc` → 在「房主 IP」欄位輸入房主的 IP（Radmin VPN 就是房主名字旁的 `26.x.x.x`）→「加入」。
4. 選單會列出已加入的人；到齊後房主按「開始遊戲」。

## 4. 連不上時
- 確認大家都在同一個虛擬網路裡、看得到彼此（Radmin VPN 的名字旁邊是綠燈）。
- 房主的防火牆要允許 `Cubeborn.exe`，或放行 **UDP 24680**。之前按錯「不允許」的話：Windows 設定 →「Windows 安全性」→「防火牆與網路保護」→「允許應用程式通過防火牆」，找到 Cubeborn 兩個都打勾。
- 遊戲版本要相同。
- 還是不行：換另一套虛擬區網軟體試試。
