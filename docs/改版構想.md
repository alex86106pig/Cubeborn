# 改版構想（2026-11-02 許家慶，討論中）

> Build 改版第 1~8 步做完、試玩一層後的檢討與新方向。**還沒定案**的都在這裡；定案的搬進 `docs/設計方向.md`，做完的刪掉。
> 已做完：魔力、墓園 1-1~1-5 小關。2026-11-03 定了「武器 / 法術 / 背包」的大方向（下面），細節還要兩位作者一起討論。

## 為什麼要改（試玩一層的感想）
- 玩家不知道自己在玩什麼、要玩什麼、在構築什麼；3 選 1 的結果不直觀，很多東西都不直觀。
- 「部位決定發動時機」連開發者都說不清楚：只有 6 個道具看部位，其他放哪裡都一樣。
- 技能遺物從 27 個技能抽、每個只能用在一種武器：只看主手時，三個選項至少一個能用的機率約 30%，大約 7 成開到全部不能用。
- Claude 的分析（對照 Sephiria、Minecraft Dungeons）：
  - 遺物（不偏向已有羈絆）、技能遺物（9 種武器）、武器詞條三個隨機來源各往不同方向，玩家抓不到主軸。
  - 羈絆門檻（物理 10 件、其他 3 件起）在一層內很難湊到，看不到「構築成形」的瞬間。
  - 系統層數多（格子形狀、部位、印記格、分支、屬性轉換、鍛造、背包）但每層都淺，要學很多、回報很小。

## 地圖與獎勵（方向贊成，細節待定）
- 第一大關「墓園」拆成 **1-1~1-5** 小關，每小關由 3~5 塊設計過的地圖拼成（不再是一張正方形）。
- **過完一小關給一次確定的選擇**（例如技能獎勵）；地圖上的祭壇 / 石棺保留，當額外的高風險高回報。
- Claude 建議：出口分岔、門上看得到獎勵種類（技能 / 詞條 / 靈魂…），讓玩家自己選方向。
- **挖墳事件只放在大關最後**（1-5，連同 Boss），1-1~1-4 是一般清怪關（許家慶 2026-11-02 決定）。
- 鐵砧固定出現在某幾小關（Claude 建議 1-3 與 Boss 前）。
- **小關拼法選 B「直線＋結尾選門」**（2026-11-02 決定）：小關內是一條主線加死路支線，出口有 2 扇門、門上看得到下一關的獎勵。
- **地圖每場隨機生成，只有特定要素固定**（2026-11-02 決定）。產生規則與固定要素在預覽頁 `mockups/map_layouts.html`。
- **形狀選「拼形＋不規則邊緣」**（2026-11-03 決定，方格、洞穴不用）：每塊 3~4 個 32 × 32 小格拼成（L、T、S、長條、方形），邊緣用雜訊往內吃 1~5 格；地形仍全是長方形，碰撞不用改。

## 武器、法術、背包（2026-11-03 許家慶定方向：Noita 簡化版）
分三層，各管一件事：

| 層 | 放什麼 | 動腦的地方 |
|---|---|---|
| **背包** | 道具，只管數值與持續被動 | 同色連塊、星位（下一節） |
| **武器** | 框架：容量、施放間隔、耗魔倍率、基礎傷害（隨機） | 挑哪一把框架 |
| **法術線** | 法術（原本的技能）＋修飾 / 觸發（原本的輔助寶石），插在武器上由左到右依序作用 | 排列順序、組合 |

### 已決定（許家慶 2026-11-03）
- 武器不再當格子；**副手拿掉**，一把武器兩條線：**左鍵線、右鍵線**。
- 數字鍵的技能欄先保留（之後可能放不綁武器的神器），法術線只有左右鍵。
- 觸發第一版四種：**命中、擊殺、消失時、每 N 秒**；其他想法（受傷時、翻滾時、招架成功…）保留。
- 武器在寶箱、門的獎勵、鐵砧之外，**怪也會掉一些**。
- 職業**不綁**武器種類。
- 拿掉：武器合成、鍛造祭壇的隨機詞條（原本就決定）、武器格子的部位與印記格。

### Noita 要留什麼、砍什麼（Claude 建議）
| Noita | 簡化版 |
|---|---|
| 法杖容量、法術依序施放 | 保留 |
| 修飾法術作用在下一發 | 保留（輔助寶石改成這種） |
| 多重施放（一次放 2~3 個） | 保留 |
| 觸發法術（命中 / 消失時放下一段） | 保留，種類照上面四種 |
| 施放延遲 + 充能時間 | 合成一個「施放間隔」 |
| 每把法杖自己的魔力池 | 拿掉，用角色共用的魔力（§31） |
| 洗牌、散射角、循環 | 拿掉 |
| 永遠施放 | 改成武器的固定詞條（例：這把劍每次揮砍都附火） |

### 普攻與右鍵：武器的「載體」（Claude 建議）
- **普攻保留，當左鍵線的第一發**：線上的修飾和觸發作用在普攻上。例：鐵鏟左鍵線 `[範圍擴大][附火][命中觸發 → 冰錐 ×3]`。左鍵線短（1~3 格）、幾乎不耗魔，是常駐手感。
- **右鍵是武器種類的固有招式，決定右鍵線「怎麼被放出來」**。右鍵線長、放真正的法術、耗魔，是爆發。
- 武器 = **種類固定**（普攻手感 + 右鍵招式）＋**框架數值隨機**；不像 Noita 全部隨機，各武器才有個性。
- 各武器的右鍵（候選，現有招式盡量留）：

| 武器 | 右鍵 | 右鍵線怎麼放 |
|---|---|---|
| 劍盾 | 按住格擋 | **招架成功才放**，傷害 ×1.5、不耗魔；沒招架到不放（高技術高回報） |
| 長劍 | 蓄力突刺 | 突刺命中點放出 |
| 鐵鏟 | 鏟起一隻怪 | **被丟出去的怪就是投射物**：修飾作用在怪身上（附火、分裂…），撞到 = 命中觸發；埋進土裡 = 那一格持續觸發 |
| 火把 | 插火把 | 插著的火把變成施法點，每 N 秒從火把位置放一次（設置型） |
| 短弓 | 扇形 5 支 | 內建多重施放，每支箭各帶一次；耗魔最高 |
| 長弓 | 按住蓄力 | 蓄力倍率乘在線上所有法術 |
| 匕首 | 影步 | 影步落點放出 |
| 驅魔權杖 | 聖光圈 | 圈內施放的法術強化，或圈內每秒放一次 |
| 法杖類（新） | 普通施法 | 純載體，容量最大 |

### 近戰與遠程的平衡（Claude 建議，數字要量）
- 同一套框架數值，偏的方向不同：

| | 近戰 | 遠程 |
|---|---|---|
| 基礎傷害 | 高 | 低 |
| 容量 | 小（2~4） | 大（4~7） |
| 耗魔倍率 | 低 | 高 |
| 命中觸發 | 近身打一群，幾乎一定觸發 | 要瞄準，常打空 |
| 風險 | 要貼近 | 安全 |

- 再加一條：**觸發條件越難，回報越高**（招架、鏟起、蓄力這類有門檻的右鍵，給倍率或減耗魔）。
- 量法：固定情境（同一條法術線、同一群怪、30 秒）在 headless 量每秒傷害、每魔力傷害、承受傷害；每種武器落在同一個區間內（例如 ±15%），做成檢查。

### 擊殺觸發不廢止，搬進法術線
- 觸發多一種「擊殺時」（Noita 沒有）：`[擊殺觸發 → 毒霧]`。現在的觸發類道具（`ItemDefs.PROCS`）大多改寫成觸發法術。
- 背包道具只留數值與持續被動（攻擊 +%、回魔、抗性）。好處：所有「會發生什麼事」都寫在法術線上，看得到是哪一格造成的。

### 取得
- **法術**：怪掉、寶箱、門的獎勵；數量多、常拿到。
- **武器**：寶箱、門的獎勵、怪偶爾掉；開局自選職業 + 武器種類。
- **鐵砧改成改造武器**：容量 +1、間隔 -10%、加一條固定詞條，三選一（取代「升稀有度 + 選詞條 + 選技能」）。

### 世界觀（Claude 提案，待決定）
- **法術 = 怪物的殘魂**：怪死後的魂被武器吸進去，所以怪會掉法術，而且掉跟自己有關的（屍犬掉撲咬、膨脹屍掉爆炸、守墓人掉落石）；跟現有的「靈魂」貨幣接得上。
- **武器 = 被詛咒的陪葬品**：墓裡挖出來的，刻著魂槽（容量）；越強的武器詛咒越重（耗魔高、或附帶缺點）。
- **鐵砧 = 鍛魂**：把武器的魂槽鑿大、刻上咒文（固定詞條）。
- **背包道具 = 遺物**：生前的護身符、骨片，顏色是它們沾染的元素。

### 風險（第一版就要處理）
1. **投射物爆量**：多重施放 × 觸發是指數成長；壓力測試 3000 個投射物時碰撞就 8.71 ms，快照單則上限 16 KB。一次施放的法術數、全場投射物都要有上限。
2. **連線**：觸發鏈全由房主算，客戶端只播特效；事件量要量。
3. **看得懂**：法術線介面要像一條流程（`揮砍 → 附火 → 命中時 → 冰錐 ×3`），不是一排圖示。
4. **工作量**：幾乎重做 Build：27 個技能 → 法術、輔助 → 修飾、武器詞條 → 框架數值、觸發道具 → 觸發法術，五個圖鑑 artifact 都要改。

## 背包（2026-11-03 許家慶決定：C 同色區塊 + D 星位）
- 道具放進背包就生效；下面的倉庫不限數量、不生效。法術不放背包（插在武器上）。
- **C 同色區塊**：道具格子有羈絆顏色，同色上下左右連成一塊，看最大那塊幾格決定羈絆等級（例：4 / 8 / 12 格），取代現在的件數門檻。
- **D 星位**：道具旁邊標一個星位，那格放了指定顏色的別的道具就啟動額外效果。
- 預覽頁 `mockups/bag_puzzle.html`；頁面上的 **A 消行鍛合不做**（許家慶 2026-11-03 拿掉）。

## 備案：導管式（YangHsu 2026-11-03 討論，先擱著）
> YangHsu 覺得「背包 + 法術線」兩套拼圖太亂、硬放在同一張盤上也是各玩各的，討論出這個做法但沒採用，留作備案。
- 法術、修飾、觸發是 1×1 的管線格，邊上有接口；武器在盤的邊緣當**發射口**（左鍵、右鍵各一，位置固定，換武器不動），沿著接上的路徑依序施放。
- 發射口本身就是載體（普攻 / 右鍵招式），不佔格；第一個法術之前的修飾與觸發都作用在載體上。
- 修飾往下游帶、**被下一個法術吃掉**（同 Noita）；觸發有兩個出口，條件成立才走的那條**重新累積**修飾。
- 線上只放行為（附火、分裂、穿透…），不放「傷害 +X%」；數字全在道具上。
- 升級只改數字、不改形狀位置：容量 = 路徑最多算幾格，超出的格子變暗不施放、不彈出。
- 跟道具的結合試過「攻擊類道具只加給貼著的法術格」（相鄰加成），覺得奇怪，沒採用。
- 沒採用的原因：比施法列難讀（要沿線追）、製作量大；道具跟管線要怎麼真的結合沒找到好解。

## 還沒決定
1. 世界觀：上面的殘魂 / 詛咒武器提案要不要用。
2. 各武器的右鍵與載體（上面的表是候選）；劍盾、鐵鏟要不要整個改掉。
3. 近戰與遠程的平衡夠不夠：要先做原型量數字再判斷。
4. 法術的元素顏色算不算進背包的同色區塊。
5. 法術線最多幾格、一次施放最多幾個法術、全場投射物上限（Claude 量完再提數字）。
6. 第一版的法術與修飾各要幾個（現有 27 個技能、5 個輔助改寫的範圍）。
7. 小關的獎勵種類（門上抽哪幾種）、每小關多長。
8. 數字鍵的神器要不要做、做幾個。
