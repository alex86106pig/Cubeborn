## 戰技與法術、技能標籤（2026-11-06 許家慶提出，參考 POE1 / POE2；下一版的方向，細節討論中）
> 起因：旋風斬、衝鋒這類會動到角色的技能放進觸發袋，玩家會失去控制；拿劍盾也能放長弓的蓄力射擊。許家慶要求下一版往這個方向做。
> **2026-11-11 許家慶決定**（規則在 `docs/系統說明.md` §45，第 1 步資料與說明框已做）：
> - 類別只有戰技 / 法術，**沒有「武器法術」**；劍氣這類算法術，傷害主要吃武器傷害、法術強度吃一點（每招兩個係數）。
> - 法術傷害選 **B**：武器多一個法術強度，介面寫**數字**、不寫百分比。分類照下面的草稿。
> - **戰技可以放觸發袋**：被觸發時角色自己做動作一路接下去，難控制是玩家的選擇。下面寫「不能被觸發」的地方都不算數。
> - **戰技的角色動作與施放時間一定要做**。法術也有施放時間（簡單、傷害低、範圍小的近乎 0，高傷害大範圍的要比較久或引導）是未來的想法，怕玩起來難受，先不做。
> - 第 2 步做了：武器需求生效、屬性加成看技能自己的屬性、技能遺物照抽只標出來。接下來：第 3 步法術改吃法術強度（平衡表量過再定數字）。
> - **幻影道具**（許家慶 2026-11-11 提出，還沒決定）：解「武器需求讓很多技能用不了」。許家慶的想法：幻影武器（放得出不是這把武器的技能）、幻影（放得出不是這把武器的戰技），不確定要不要分兩種、是拿著就有效還是要放進袋子、要限量鑲嵌還是單純佔格子。
>   - Claude 建議：只做一種，做成**修飾**（透明格蓋在技能上才有效，沿用現有規則）。蓋住的技能不看武器需求，由幻影替你放：法術是幻影武器飛出來放，戰技是幻影替你做動作、角色不受影響（順便解戰技在觸發袋裡難控制）。代價是傷害打折（先抓 60%）與耗魔 +30%（跟分裂、火焰化同級）。
>   - 不建議「拿著就全部有效」：等於一格道具把武器需求整條規則關掉，會變成必拿。整袋有效的版本可以之後做成橘色（像回響那樣改寫整個袋子）。
- **技能有三個各自獨立的屬性**（取代「法術一定吃法術強度」）：
  | 屬性 | 決定什麼 | 選項 |
  |---|---|---|
  | 類別 | 有沒有角色動作、能不能被觸發 | 戰技（之後全部要有角色動作，有前搖後搖，不能被觸發）／法術（被觸發時沒有動作、瞬間放出） |
  | 傷害來源 | 吃哪個數字 | 武器傷害／法術強度。預設戰技吃武器、法術吃法強，例外是**武器法術**（下面） |
  | 傷害類型 | 看哪種抗性、吃哪種加成 | 現有 8 種（`StatDefs.DAMAGE_TYPES`）；每招已經有 `damage_type` |
- POE 的做法：類別只有戰技 / 法術兩種，其他是一般標籤（移動、引導、近戰、投射…）；觸發基本上只接法術、不接引導；戰技有武器需求（要弓、要盾），武器不對就不能用。**不分「瞬發 / 操控」戰技**（許家慶 11-06 覺得奇怪，POE 也沒有）。
- **四條方向可以同時成立**（許家慶 11-06 同意都做）：
  1. 平衡目標：觸發流派與手動流派的傷害 / 清怪速度要差不多（照平衡表量每分鐘輸出）。
  2. **武器法術**：看起來不像角色在揮武器的（從武器飛出、從天而降、地上冒出）改成法術，可以觸發，但**吃武器傷害、要符合武器**。例：劍氣 = 法術 + 吃武器傷害 + 要近戰武器 → 拿劍放很痛、拿法杖不能用。
  3. **亡魂分身**：特殊的觸發袋（或之後的輔助），被觸發的戰技由身邊的亡魂替你做動作、傷害打折（例如 50%），角色不受影響（像 POE 的幻影射手、先祖戰士）。
  4. **替換下一次普攻**（像 POE2 的連段）：左 / 右鍵的袋子放戰技 = 每 N 下之後，下一次自己按的左鍵變成那招。
  - 其他討論過的：觸發改成累積「蓄能」、花在手動戰技上（像充能球）；圖騰 / 陷阱替你重複放（適合當一種技能，不適合當整體規則）。
- **法術傷害從哪裡來**（Claude 建議 B，許家慶還沒定）：
  - A 照舊吃武器傷害：分戰技 / 法術就只剩「能不能觸發」。
  - **B 武器兩個數字**：武器傷害（給戰技與武器法術）+ 法術強度（給一般法術）。技能強度公式不變（技能是某個基準的 %）。例：劍盾、雙匕首、弓、鐵鏟法強約 40%，火把約 70%，法杖、權杖約 100%（數字要量）。
  - C 照 POE 法術自己有基傷、武器只給 +%：法術跟撿武器脫鉤，roguelike 撿到好武器的爽感沒了，平衡表要整套重算。
  - D 角色身上的法術強度屬性：跟 B 很像，但多一個到處堆的屬性，主袋會更擠。
  - 加成道具：通用「傷害 +%」最多（兩邊都吃）；少數「戰技傷害」「法術傷害」專屬；屬性加成看**技能自己**的傷害類型。
  - 順便要修：現在 `Player.pct_damage`（`sim/player.gd`）的屬性加成看的是武器的 `damage_type`，拿劍放冰霜新星吃的是物理加成。
- **分類草稿**（Claude 暫定，還沒確認）：
  - 一般法術：冰霜新星、隕石、閃電鏈、聖光柱、骸骨衛士、祝福、煙霧彈、嘲諷、冥府之門、天譴、星位、亡者軍勢、魂泉、積怨、火瓶。
  - 武器法術：劍氣、裂地斬（近戰武器）、飛刀扇（匕首）、箭雨（弓）、火焰新星（火把）。雙匕首、弓、鐵鏟各要再新做 1~2 個，否則那些職業沒有觸發流派。
  - 戰技：盾擊、震地（盾）、連射、雷箭、狙擊、冰凍箭（弓）、砸地、拋土、活埋（鏟）、旋風斬、千刃風暴、噬魂刃、衝鋒斬、突刺、背襲、火焰奔襲、盾衝、躍射、掘地。帶「移動」標籤的法術也不能觸發。
  - 影響：守墓騎士（震地）、遊俠（連射）、竊影者（飛刀扇）、掘墓人（砸地）的起始技能是戰技，開局的觸發袋要改給起始法術或不給（還沒定）。
- **更遠的方向：格子綁在技能上、觸發改成輔助石**（許家慶 11-06 說整套重做沒關係，還在想）：
  - 共通：技能石有插槽（稀有度越高越多）；輔助分發動方式（每顆最多 1 個，按鍵 1~3、Q 也是一種發動石）、形態、傷害、功能；標籤擋插槽（發動方式只能插法術）；武器也是一顆石頭，插的輔助作用在普攻與右鍵。
  - 甲：純 POE2 一列插槽（最好懂，但拼圖、羈絆、技能銜接都沒了）。
  - **乙：輔助碰到技能才生效**（Claude 建議）：一顆觸發碰到好幾顆技能 = 原本的觸發袋，照左上 → 右下依序放（保留 §43 技能銜接）。補充規則：技能碰到兩種發動方式就標紅不放；發動石有連接點上限；分「連段型」（全部放一輪、燒魔）與「輪替型」（一次放下一顆）兩種發動石。
  - 丙：一列插槽 + 「法陣」元技能（放 2~4 顆法術依序放）。
  - 可留用：技能行為、`aim_at`、觸發掛鉤、每 N 下、`BagDefs.POWER`、技能銜接、修飾的標籤判斷、稀有度預算；背包合併模式可以當新背包的底子。
- **下次接著討論**：各武器的法術強度數字與劍氣這類的混合比例（第 3 步量）、亡魂分身與替換普攻要不要做、要不要先做構想頁（`mockups/戰技與觸發.html`，六個方向並排 + 同一個守墓騎士示範）給兩位作者選。

## 為什麼要改（試玩一層的感想）
- 玩家不知道自己在玩什麼、要玩什麼、在構築什麼；3 選 1 的結果不直觀，很多東西都不直觀。
- 「部位決定發動時機」連開發者都說不清楚：只有 6 個道具看部位，其他放哪裡都一樣。
- 技能遺物從 27 個技能抽、每個只能用在一種武器：只看主手時，三個選項至少一個能用的機率約 30%，大約 7 成開到全部不能用。
- Claude 的分析（對照 Sephiria、Minecraft Dungeons）：
  - 遺物（不偏向已有羈絆）、技能遺物（9 種武器）、武器詞條三個隨機來源各往不同方向，玩家抓不到主軸。
  - 羈絆門檻（物理 10 件、其他 3 件起）在一層內很難湊到，看不到「構築成形」的瞬間。
  - 系統層數多（格子形狀、部位、印記格、分支、屬性轉換、鍛造、背包）但每層都淺，要學很多、回報很小。

- **挖墳事件只放在大關最後**（1-5，連同 Boss），1-1~1-4 是一般清怪關（許家慶 2026-11-02 決定）。

- **地圖每場隨機生成，只有特定要素固定**（2026-11-02 決定）。產生規則與固定要素在預覽頁 `mockups/map_layouts.html`。

## 觸發袋：細節（Claude 建議，YangHsu 2026-11-04 同意；數字要量）
### 右鍵怎麼算觸發（各武器的「載體」）
右鍵袋（接在主袋右邊的袋子）在右鍵招式觸發時發動；同一個命中袋接在不同武器上，發動次數不同，武器的個性從這裡來（**觸發越難、回報越高**）。

| 武器 | 右鍵 | 右鍵的命中 / 出手怎麼算 |
|---|---|---|
| 劍盾 | 按住格擋 | **招架成功**才算右鍵命中，效果 ×1.5、不耗魔 |
| 長劍 | 蓄力突刺 | 突刺命中點 |
| 鐵鏟 | 鏟起一隻怪 | 丟出去的怪撞到東西算命中，可能一次撞好幾隻 |
| 火把 | 插火把 | 插著的火把當施法點 |
| 短弓 | 扇形 5 支 | 每支箭各自算命中，發動次數多、耗魔高 |
| 長弓 | 按住蓄力 | 蓄力倍率乘在右鍵袋的效果上 |
| 匕首 | 影步 | 影步落點 |
| 驅魔權杖 | 聖光圈 | 圈內每秒算一次 |

### 近戰與遠程的平衡（數字要量）
- 近戰基礎傷害高、要貼近、命中幾乎一定觸發；遠程安全、要瞄準、常打空。
- 量法：固定情境（同一組袋子、同一群怪、30 秒）在 headless 量每秒傷害、每魔力傷害、承受傷害；每種武器落在同一個區間內（例如 ±15%），做成檢查。

### 世界觀（Claude 提案，YangHsu 2026-11-04 採用）
- **技能 / 效果 = 怪物的殘魂**：怪會掉跟自己有關的（屍犬掉撲咬、膨脹屍掉爆炸、守墓人掉落石）；跟「靈魂」貨幣接得上。
- **觸發袋 = 菁英怪的執念**：菁英怪掉跟牠招式有關的袋子（膨脹屍 → 擊殺袋、屍犬 → 翻滾袋、骷髏弓手 → 命中袋）。
- **鐵砧 = 鍛魂**：把袋子鑿大、改觸發。
- **背包道具 = 遺物**：生前的護身符、骨片，顏色是它們沾染的元素。

### 風險（第一版就要處理）
1. **投射物爆量**：觸發的效果再觸發會連鎖；壓力測試 3000 個投射物時碰撞就 8.71 ms，快照單則上限 16 KB。觸發的效果不再觸發袋子（只有載體會），全場投射物要有上限。
2. **連線**：觸發全由房主算，客戶端只播特效；事件量要量（v0.65.0 剛把頻寬減半）。
3. **看得懂**：袋子上寫觸發名稱與按鍵，效果只寫「發生什麼」。

## 備案（討論過、沒採用）
### Noita 法術線（許家慶 2026-11-03 定方向，2026-11-04 被觸發袋取代）
- 武器是框架（容量、施放間隔、耗魔倍率），左鍵線、右鍵線插法術、修飾、觸發，由左到右依序作用；普攻 / 右鍵招式是線頭的載體。
- 修飾被下一個法術吃掉（同 Noita）；觸發只帶下一個法術。線上只放行為（附火、分裂），不放「傷害 +X%」。
- 沒採用的原因：跟背包（拼形狀）是兩套平行的拼圖，加上連結規則後太亂；把兩者合在同一張盤上（施法列）也是各玩各的。

### 導管式（YangHsu 2026-11-03 討論）
- 法術、修飾、觸發是 1×1 的管線格，邊上有接口；武器在盤的邊緣當**發射口**（左鍵、右鍵各一，位置固定），沿著接上的路徑依序施放；觸發有兩個出口（分岔）。
- 修飾往下游帶、被下一個法術吃掉；觸發後條件成立才走的那條重新累積修飾。升級只改數字、不改形狀位置。
- 跟道具的結合試過「攻擊類道具只加給貼著的法術格」（相鄰加成），覺得奇怪。
- 沒採用的原因：比直線難讀（要沿線追）、製作量大；道具跟管線要怎麼真的結合沒找到好解。

### 背包 A 消行鍛合、方案 A 背包分區
- A 消行鍛合（填滿一行可以鍛合升級、鎖住）：許家慶 2026-11-03 拿掉。
- 背包分區 = 觸發時機（區域由武器決定）：YangHsu 2026-11-04 覺得太無聊。
