## 為什麼要改（試玩一層的感想）
- 玩家不知道自己在玩什麼、要玩什麼、在構築什麼；3 選 1 的結果不直觀，很多東西都不直觀。
- 「部位決定發動時機」連開發者都說不清楚：只有 6 個道具看部位，其他放哪裡都一樣。
- 技能遺物從 27 個技能抽、每個只能用在一種武器：只看主手時，三個選項至少一個能用的機率約 30%，大約 7 成開到全部不能用。
- Claude 的分析（對照 Sephiria、Minecraft Dungeons）：
  - 遺物（不偏向已有羈絆）、技能遺物（9 種武器）、武器詞條三個隨機來源各往不同方向，玩家抓不到主軸。
  - 羈絆門檻（物理 10 件、其他 3 件起）在一層內很難湊到，看不到「構築成形」的瞬間。
  - 系統層數多（格子形狀、部位、印記格、分支、屬性轉換、鍛造、背包）但每層都淺，要學很多、回報很小。

## 地圖與獎勵（方向贊成，細節待定）
- 第一大關「墓園」拆成 **1-1~1-5** 小關，每小關由 3~5 塊設計過的地圖拼成（不再是一張正方形）。
- **過完一小關給一次確定的選擇**（例如技能獎勵）；地圖上的祭壇 / 石棺保留，當額外的高風險高回報。
- Claude 建議：出口分岔、門上看得到獎勵種類（技能 / 詞條 / 靈魂…），讓玩家自己選方向。
- **挖墳事件只放在大關最後**（1-5，連同 Boss），1-1~1-4 是一般清怪關（許家慶 2026-11-02 決定）。
- 鐵砧固定出現在某幾小關（Claude 建議 1-3 與 Boss 前）。
- **小關拼法選 B「直線＋結尾選門」**（2026-11-02 決定）：小關內是一條主線加死路支線，出口有 2 扇門、門上看得到下一關的獎勵。
- **地圖每場隨機生成，只有特定要素固定**（2026-11-02 決定）。產生規則與固定要素在預覽頁 `mockups/map_layouts.html`。
- **形狀選「拼形＋不規則邊緣」**（2026-11-03 決定，方格、洞穴不用）：每塊 3~4 個 32 × 32 小格拼成（L、T、S、長條、方形），邊緣用雜訊往內吃 1~5 格；地形仍全是長方形，碰撞不用改。

## 觸發袋：細節（Claude 建議，YangHsu 2026-11-04 同意；數字要量）
### 右鍵怎麼算觸發（各武器的「載體」）
右鍵袋（接在主袋右邊的袋子）在右鍵招式觸發時發動；同一個命中袋接在不同武器上，發動次數不同，武器的個性從這裡來（**觸發越難、回報越高**）。

| 武器 | 右鍵 | 右鍵的命中 / 出手怎麼算 |
|---|---|---|
| 劍盾 | 按住格擋 | **招架成功**才算右鍵命中，效果 ×1.5、不耗魔 |
| 長劍 | 蓄力突刺 | 突刺命中點 |
| 鐵鏟 | 鏟起一隻怪 | 丟出去的怪撞到東西算命中，可能一次撞好幾隻 |
| 火把 | 插火把 | 插著的火把當施法點 |
| 短弓 | 扇形 5 支 | 每支箭各自算命中，發動次數多、耗魔高 |
| 長弓 | 按住蓄力 | 蓄力倍率乘在右鍵袋的效果上 |
| 匕首 | 影步 | 影步落點 |
| 驅魔權杖 | 聖光圈 | 圈內每秒算一次 |

### 近戰與遠程的平衡（數字要量）
- 近戰基礎傷害高、要貼近、命中幾乎一定觸發；遠程安全、要瞄準、常打空。
- 量法：固定情境（同一組袋子、同一群怪、30 秒）在 headless 量每秒傷害、每魔力傷害、承受傷害；每種武器落在同一個區間內（例如 ±15%），做成檢查。

### 世界觀（Claude 提案，YangHsu 2026-11-04 採用）
- **技能 / 效果 = 怪物的殘魂**：怪會掉跟自己有關的（屍犬掉撲咬、膨脹屍掉爆炸、守墓人掉落石）；跟「靈魂」貨幣接得上。
- **觸發袋 = 菁英怪的執念**：菁英怪掉跟牠招式有關的袋子（膨脹屍 → 擊殺袋、屍犬 → 翻滾袋、骷髏弓手 → 命中袋）。
- **鐵砧 = 鍛魂**：把袋子鑿大、改觸發。
- **背包道具 = 遺物**：生前的護身符、骨片，顏色是它們沾染的元素。

### 風險（第一版就要處理）
1. **投射物爆量**：觸發的效果再觸發會連鎖；壓力測試 3000 個投射物時碰撞就 8.71 ms，快照單則上限 16 KB。觸發的效果不再觸發袋子（只有載體會），全場投射物要有上限。
2. **連線**：觸發全由房主算，客戶端只播特效；事件量要量（v0.65.0 剛把頻寬減半）。
3. **看得懂**：袋子上寫觸發名稱與按鍵，效果只寫「發生什麼」。

## 備案（討論過、沒採用）
### Noita 法術線（許家慶 2026-11-03 定方向，2026-11-04 被觸發袋取代）
- 武器是框架（容量、施放間隔、耗魔倍率），左鍵線、右鍵線插法術、修飾、觸發，由左到右依序作用；普攻 / 右鍵招式是線頭的載體。
- 修飾被下一個法術吃掉（同 Noita）；觸發只帶下一個法術。線上只放行為（附火、分裂），不放「傷害 +X%」。
- 沒採用的原因：跟背包（拼形狀）是兩套平行的拼圖，加上連結規則後太亂；把兩者合在同一張盤上（施法列）也是各玩各的。

### 導管式（YangHsu 2026-11-03 討論）
- 法術、修飾、觸發是 1×1 的管線格，邊上有接口；武器在盤的邊緣當**發射口**（左鍵、右鍵各一，位置固定），沿著接上的路徑依序施放；觸發有兩個出口（分岔）。
- 修飾往下游帶、被下一個法術吃掉；觸發後條件成立才走的那條重新累積修飾。升級只改數字、不改形狀位置。
- 跟道具的結合試過「攻擊類道具只加給貼著的法術格」（相鄰加成），覺得奇怪。
- 沒採用的原因：比直線難讀（要沿線追）、製作量大；道具跟管線要怎麼真的結合沒找到好解。
